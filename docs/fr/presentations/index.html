Présentations

Diapositives de l’atelier technique sur les comptes de l’énergie et des émissions atmosphériques, Tunis, 7 au 11 décembre 2026

Chaque présentation correspond à une séance de l’atelier. Les graphiques et les chiffres sont lus dans les mêmes tableaux que les documents ; les diapositives suivent donc les données. Ouvrez une présentation, puis appuyez sur F pour le plein écran, sur S pour la vue de l’orateur et sur Échap pour une vue d’ensemble des diapositives.
