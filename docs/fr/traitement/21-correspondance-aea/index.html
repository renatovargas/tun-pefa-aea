Des catégories de l’inventaire aux branches d’activité

Matrice de conversion par défaut de l’outil I2A et matrice tunisienne par branche du TRE

Auteur·rice
Affiliation

Renato Vargas

Consultant du FMI

1 Objet

L’inventaire classe les émissions par processus : combustion dans les industries de l’énergie, transport routier, fermentation entérique, etc. Les comptes AEA les classent par unité économique qui les produit, avec les branches d’activité des comptes nationaux et les ménages (Eurostat, 2015). L’outil I2A du FMI (International Monetary Fund, 2026; Pegoue, 2026) fait ce passage avec une matrice de conversion. Elle donne, pour chaque catégorie CRT et chaque gaz, la part des émissions attribuée à chaque activité.

Cette page examine la matrice par défaut de l’outil, puis construit une matrice tunisienne par branche du TRE, sur le modèle de la matrice de concordance des comptes PEFA (page 12). Les deux comptes partagent ainsi les mêmes branches et les mêmes clés de répartition.

2 La matrice par défaut de l’outil

Le classeur de l’outil contient deux jeux de tables. Les feuilles actives portent des facteurs de démonstration, tirés au hasard, pour l’exemple du Canada. Les tables par défaut sont dans les feuilles dont le nom finit par « _Def ». Le module scripts/outils_fmi.py1 lit ces dernières, avec les mêmes définitions de plages que les plages nommées du classeur.

La matrice par défaut compte une ligne par gaz et par catégorie CRT, et une colonne par activité. Les activités sont les divisions de la nomenclature européenne NACE, proche de la CITI, les ménages par fonction de consommation et les éléments de passage.

entete = [str(c) for c in plages["Conversion_Matrix"][0]]

def section_outil(activite: str) -> str:
    """Section de la CITI d'une activité de l'outil, dans les codes de section du site."""
    if activite.startswith("HH"):
        return "HH"
    if activite[0] in "ABCDEFH" and not activite.startswith(("NRA", "NRT")):
        return activite[0]
    if activite in ("LULUCF", "OTHER") or activite.startswith(("NRA", "NRT")):
        return activite
    return "Other"

3 La correspondance tunisienne

La table data/nomenclatures/crt_vers_activites.csv associe des préfixes de codes CRT aux activités de data/nomenclatures/activites.csv, c’est-à-dire les 24 branches du TRE et les ménages. Chaque catégorie de l’inventaire prend la ligne dont le préfixe est le plus long. Un préfixe court (« 3 » pour l’agriculture) couvre ainsi tout un secteur, et un préfixe long (« 1.B.2.a.iv » pour le raffinage et le stockage du pétrole) corrige un cas particulier. La colonne justification explique chaque choix. Les émissions de l’UTCATF vont à la pseudo-activité LULUCF de l’outil, hors des comptes.

Chaque catégorie de l’inventaire doit trouver une ligne. Les codes de l’aviation et de la navigation intérieures en ont besoin aussi, même sans émissions dans l’inventaire, car l’outil y fait entrer les données de l’OCDE sur le transport des résidents (page 22). Sans ligne dans la matrice, ces données seraient perdues.

PREFIXES = correspondance["prefixe"].to_list()


def regle(code: str) -> str | None:
    """Préfixe le plus long de la correspondance qui couvre un code (« 3. » est couvert par « 3 »)."""
    code = code.rstrip(".")
    couvrants = [p for p in PREFIXES if code == p or code.startswith(p + ".")]
    return max(couvrants, key=len) if couvrants else None


# Les données de l'OCDE entrent par les codes de l'aviation et de la navigation intérieures
CODES_OCDE = [l[1] for l in plages["CRT"][1:] if l[11] in ("Domestic Aviation", "Domestic Navigation")]
codes = pl.concat([inventaire.select("code_outil"), pl.DataFrame({"code_outil": CODES_OCDE})]).unique().with_columns(
    prefixe=pl.col("code_outil").map_elements(regle, return_dtype=pl.String)
)
assert codes["prefixe"].null_count() == 0, f"Codes sans correspondance : {codes.filter(pl.col('prefixe').is_null())['code_outil'].to_list()}"

4 Clés de répartition

Deux catégories regroupent plusieurs branches. Le transport routier (1.A.3.b) est le fait de toutes les branches et des ménages. La combustion dans le commerce et les administrations (1.A.4.a) couvre toutes les branches de services. Les comptes PEFA répartissent les flux correspondants du bilan avec des clés tirées du TRE (page 11). Les comptes AEA reprennent ces clés, pour que les émissions suivent l’énergie. Les climatiseurs des véhicules et les climatiseurs fixes (2.F.1.e et 2.F.1.f) suivent les mêmes clés.

cles = (

5 La matrice tunisienne

La matrice tunisienne a une ligne par année, code de l’outil et activité. Le facteur vaut 1 pour une attribution directe et la clé de l’année pour une répartition. Les facteurs d’un code somment à 1. La matrice vaut pour tous les gaz, car les règles ne dépendent pas du gaz.

annees = pl.DataFrame({"annee": ANNEES}, schema={"annee": pl.Int16})
regles = codes.join(correspondance, on="prefixe")
directes = regles.filter(pl.col("methode") == "direct").join(annees, how="cross").with_columns(facteur=pl.lit(1.0))
reparties = regles.filter(pl.col("methode") == "cle").drop("activite").join(cles, on="cle")
COLONNES = ["annee", "code_outil", "activite", "facteur", "prefixe", "methode", "cle"]
matrice = pl.concat([directes.select(COLONNES), reparties.select(COLONNES)]).sort("annee", "code_outil", "activite")

sommes = matrice.group_by("annee", "code_outil").agg(pl.col("facteur").sum())
assert (sommes["facteur"] - 1).abs().max() < 1e-9, "Les facteurs d'un code doivent sommer à 1"
assert set(matrice["activite"]) <= set(activites["code"]) | {"LULUCF"}, "Activité inconnue"

6 Différences avec la matrice par défaut

Le tableau suivant compare, pour les catégories qui émettent en 2022, la section de la CITI principale de la matrice par défaut et celle de la matrice tunisienne. Les lignes marquées oui dans la colonne section_modifiee changent le résultat, même au niveau des sections. Les autres ajoutent seulement le détail par branche.

SECTION_SITE = dict(activites.select("code", "section_fmi").iter_rows()) | {"LULUCF": "LULUCF"}
emissions_2022 = (
    inventaire.filter(pl.col("annee") == 2022)
    .group_by("code_outil")
    .agg(pl.col("kt_eq_co2").sum())
    .filter(pl.col("kt_eq_co2").abs() > 0.05)
)
defaut = (
    matrice_defaut.filter(pl.col("facteur") > 0)
    .join(inventaire.filter(pl.col("annee") == 2022).select(POLLUTANT="gaz", Source_Code="code_outil").unique(), on=["POLLUTANT", "Source_Code"])
    .with_columns(section=pl.col("activite_outil").map_elements(section_outil, return_dtype=pl.String))
    .group_by("Source_Code", "section")
    .agg(pl.col("facteur").sum())
    .sort("facteur", descending=True)
    .group_by("Source_Code", maintain_order=True)
    .agg(section_defaut=pl.col("section").first(), activites_defaut=pl.col("section").unique().sort().str.join(", "))
    .rename({"Source_Code": "code_outil"})
)
tunisie = (
    matrice.filter(pl.col("annee") == 2022)
    .with_columns(section=pl.col("activite").replace_strict(SECTION_SITE))
    .group_by("code_outil", "prefixe")
    .agg(
        activites_tunisie=pl.when(pl.col("methode").first() == "cle")
        .then(pl.lit("clé ") + pl.col("cle").first())
        .otherwise(pl.col("activite").unique().sort().str.join(", ")),
        section_tunisie=pl.col("section").sort_by("facteur", descending=True).first(),
    )
)
differences = (
    emissions_2022.join(tunisie, on="code_outil", how="left")
    .join(defaut, on="code_outil", how="left")
    .with_columns(
        section_modifiee=pl.when(pl.col("section_defaut") != pl.col("section_tunisie")).then(pl.lit("oui"))
        .when(pl.col("section_defaut").is_null()).then(pl.lit("sans facteur"))
        .otherwise(pl.lit("non")),
        kt_eq_co2_2022=pl.col("kt_eq_co2").round(1),

    .sort("code_outil")
    .select("code_outil", "kt_eq_co2_2022", "section_defaut", "activites_defaut", "section_tunisie", "activites_tunisie", "section_modifiee")
)

Les choix qui s’écartent de la matrice par défaut sont à valider avec l’INS et l’ANME. Les principaux sont la combustion dans le commerce et les administrations, attribuée aux services et non à la construction ; la combustion résidentielle, attribuée aux ménages ; le transport routier, réparti entre les branches et les ménages au lieu d’aller au transport ; les émissions fugitives du transport et de la distribution du gaz, attribuées à la branche électricité et gaz. Deux points sont propres à l’inventaire tunisien. La catégorie 1.A.1.c.i (fabrication de combustibles solides) porte des émissions importantes et est attribuée à l’extraction d’hydrocarbures avec le reste de 1.A.1.c. La catégorie 1.A.4.b.ii (engins mobiles du secteur résidentiel) porte toute la combustion des ménages, chaque année.

## Objet

L'inventaire classe les émissions par processus : combustion dans les industries de l'énergie, transport routier, fermentation entérique, etc. Les comptes AEA les classent par unité économique qui les produit, avec les branches d'activité des comptes nationaux et les ménages [@eurostat2015aea]. L'outil I2A du FMI [@pegoue2026i2a; @imf2026i2a] fait ce passage avec une matrice de conversion. Elle donne, pour chaque catégorie CRT et chaque gaz, la part des émissions attribuée à chaque activité.

Cette page examine la matrice par défaut de l'outil, puis construit une matrice tunisienne par branche du TRE, sur le modèle de la matrice de concordance des comptes PEFA (page 12). Les deux comptes partagent ainsi les mêmes branches et les mêmes clés de répartition.

```{python}
#| label: parametres
import sys

import polars as pl

sys.path.insert(0, "scripts")
import outils_fmi as of

SORTIE = "data/intermediaires/matrice_aea_tunisie.parquet"
SORTIE_DIFFERENCES = "data/intermediaires/matrice_aea_differences.parquet"
CODES = {"code": pl.String, "activite": pl.String, "prefixe": pl.String}

inventaire = pl.read_parquet("data/intermediaires/inventaire_ges.parquet").filter(pl.col("perimetre") != "pour_memoire")
cles_pefa = pl.read_parquet("data/intermediaires/cles_activites.parquet")
activites = pl.read_csv("data/nomenclatures/activites.csv", schema_overrides=CODES)
correspondance = pl.read_csv("data/nomenclatures/crt_vers_activites.csv", schema_overrides=CODES)
plages = of.plages_i2a()
ANNEES = sorted(inventaire["annee"].unique().to_list())
```

## La matrice par défaut de l'outil

Le classeur de l'outil contient deux jeux de tables. Les feuilles actives portent des facteurs de démonstration, tirés au hasard, pour l'exemple du Canada. Les tables par défaut sont dans les feuilles dont le nom finit par « _Def ». Le module `scripts/outils_fmi.py`[^outils] lit ces dernières, avec les mêmes définitions de plages que les plages nommées du classeur.

[^outils]: Code source : <https://github.com/renatovargas/tun-pefa-aea/blob/main/scripts/outils_fmi.py>.

La matrice par défaut compte une ligne par gaz et par catégorie CRT, et une colonne par activité. Les activités sont les divisions de la nomenclature européenne NACE, proche de la CITI, les ménages par fonction de consommation et les éléments de passage.

```{python}
#| label: matrice-defaut
entete = [str(c) for c in plages["Conversion_Matrix"][0]]
ACTIVITES_OUTIL = entete[5:]
matrice_defaut = (
    pl.DataFrame(plages["Conversion_Matrix"][1:], schema=entete, orient="row", infer_schema_length=None)
    .unpivot(index=["POLLUTANT", "Source_Code", "Check"], on=ACTIVITES_OUTIL, variable_name="activite_outil", value_name="facteur")
    .with_columns(pl.col("facteur").cast(pl.Float64).fill_null(0), pl.col("Check").cast(pl.Float64).fill_null(0))
)


def section_outil(activite: str) -> str:
    """Section de la CITI d'une activité de l'outil, dans les codes de section du site."""
    if activite.startswith("HH"):
        return "HH"
    if activite[0] in "ABCDEFH" and not activite.startswith(("NRA", "NRT")):
        return activite[0]
    if activite in ("LULUCF", "OTHER") or activite.startswith(("NRA", "NRT")):
        return activite
    return "Other"


print(f"{matrice_defaut['Source_Code'].n_unique()} catégories, {len(ACTIVITES_OUTIL)} activités, gaz : {sorted(matrice_defaut['POLLUTANT'].unique())}")
matrice_defaut.filter(pl.col("POLLUTANT") == "CO2", pl.col("facteur") > 0, pl.col("Source_Code").is_in(["1.A.3.b", "1.A.4.a", "1.A.4.b", "1.A.4.c", "3.A", "5.A"]))
```

Pour certaines catégories, la matrice par défaut n'a aucun facteur. L'outil laisse alors leurs émissions sans activité, et elles disparaissent des comptes sans message. C'est le cas des sols agricoles (3.D), dont les émissions de N2O sont importantes en Tunisie.

```{python}
#| label: sans-facteur
sans_facteur = matrice_defaut.filter(pl.col("Check") == 0).select(gaz="POLLUTANT", code_outil="Source_Code").unique()
(
    inventaire.filter(pl.col("perimetre") == "inventaire")
    .join(sans_facteur, on=["gaz", "code_outil"])
    .group_by("annee", "code_outil")
    .agg(pl.col("kt_eq_co2").sum().round(1))
    .sort("annee")
    .pivot("annee", index="code_outil", values="kt_eq_co2")
    .sort("code_outil")
)
```

## La correspondance tunisienne

La table `data/nomenclatures/crt_vers_activites.csv` associe des préfixes de codes CRT aux activités de `data/nomenclatures/activites.csv`, c'est-à-dire les 24 branches du TRE et les ménages. Chaque catégorie de l'inventaire prend la ligne dont le préfixe est le plus long. Un préfixe court (« 3 » pour l'agriculture) couvre ainsi tout un secteur, et un préfixe long (« 1.B.2.a.iv » pour le raffinage et le stockage du pétrole) corrige un cas particulier. La colonne `justification` explique chaque choix. Les émissions de l'UTCATF vont à la pseudo-activité `LULUCF` de l'outil, hors des comptes.

```{python}
#| label: correspondance
correspondance.select("prefixe", "activite", "methode", "cle", "justification")
```

Chaque catégorie de l'inventaire doit trouver une ligne. Les codes de l'aviation et de la navigation intérieures en ont besoin aussi, même sans émissions dans l'inventaire, car l'outil y fait entrer les données de l'OCDE sur le transport des résidents (page 22). Sans ligne dans la matrice, ces données seraient perdues.

```{python}
#| label: couverture
PREFIXES = correspondance["prefixe"].to_list()


def regle(code: str) -> str | None:
    """Préfixe le plus long de la correspondance qui couvre un code (« 3. » est couvert par « 3 »)."""
    code = code.rstrip(".")
    couvrants = [p for p in PREFIXES if code == p or code.startswith(p + ".")]
    return max(couvrants, key=len) if couvrants else None


# Les données de l'OCDE entrent par les codes de l'aviation et de la navigation intérieures
CODES_OCDE = [l[1] for l in plages["CRT"][1:] if l[11] in ("Domestic Aviation", "Domestic Navigation")]
codes = pl.concat([inventaire.select("code_outil"), pl.DataFrame({"code_outil": CODES_OCDE})]).unique().with_columns(
    prefixe=pl.col("code_outil").map_elements(regle, return_dtype=pl.String)
)
assert codes["prefixe"].null_count() == 0, f"Codes sans correspondance : {codes.filter(pl.col('prefixe').is_null())['code_outil'].to_list()}"
print(f"{codes.height} codes de l'outil (inventaire et OCDE : {CODES_OCDE}), tous couverts par {codes['prefixe'].n_unique()} lignes de la correspondance")
```

## Clés de répartition

Deux catégories regroupent plusieurs branches. Le transport routier (1.A.3.b) est le fait de toutes les branches et des ménages. La combustion dans le commerce et les administrations (1.A.4.a) couvre toutes les branches de services. Les comptes PEFA répartissent les flux correspondants du bilan avec des clés tirées du TRE (page 11). Les comptes AEA reprennent ces clés, pour que les émissions suivent l'énergie. Les climatiseurs des véhicules et les climatiseurs fixes (2.F.1.e et 2.F.1.f) suivent les mêmes clés.

```{python}
#| label: cles
cles = (
    cles_pefa.filter(pl.col("methode") == "cle")
    .select("annee", cle="flux_modele", activite="activite", facteur="facteur")
    .group_by("annee", "cle", "activite")
    .agg(pl.col("facteur").sum())
)
assert set(correspondance["cle"].drop_nulls()) <= set(cles["cle"]), "Clé inconnue dans la correspondance"
cles.filter(pl.col("annee") == 2022).with_columns((pl.col("facteur") * 100).round(1)).pivot("cle", index="activite", values="facteur").sort("activite")
```

## La matrice tunisienne

La matrice tunisienne a une ligne par année, code de l'outil et activité. Le facteur vaut 1 pour une attribution directe et la clé de l'année pour une répartition. Les facteurs d'un code somment à 1. La matrice vaut pour tous les gaz, car les règles ne dépendent pas du gaz.

```{python}
#| label: matrice-tunisienne
annees = pl.DataFrame({"annee": ANNEES}, schema={"annee": pl.Int16})
regles = codes.join(correspondance, on="prefixe")
directes = regles.filter(pl.col("methode") == "direct").join(annees, how="cross").with_columns(facteur=pl.lit(1.0))
reparties = regles.filter(pl.col("methode") == "cle").drop("activite").join(cles, on="cle")
COLONNES = ["annee", "code_outil", "activite", "facteur", "prefixe", "methode", "cle"]
matrice = pl.concat([directes.select(COLONNES), reparties.select(COLONNES)]).sort("annee", "code_outil", "activite")

sommes = matrice.group_by("annee", "code_outil").agg(pl.col("facteur").sum())
assert (sommes["facteur"] - 1).abs().max() < 1e-9, "Les facteurs d'un code doivent sommer à 1"
assert set(matrice["activite"]) <= set(activites["code"]) | {"LULUCF"}, "Activité inconnue"
print(f"{matrice.height} lignes, {matrice['code_outil'].n_unique()} codes, {matrice['activite'].n_unique()} activités")
matrice.filter(pl.col("annee") == 2022, pl.col("code_outil").str.starts_with("1.A.3"))
```

## Différences avec la matrice par défaut

Le tableau suivant compare, pour les catégories qui émettent en 2022, la section de la CITI principale de la matrice par défaut et celle de la matrice tunisienne. Les lignes marquées `oui` dans la colonne `section_modifiee` changent le résultat, même au niveau des sections. Les autres ajoutent seulement le détail par branche.

```{python}
#| label: differences
SECTION_SITE = dict(activites.select("code", "section_fmi").iter_rows()) | {"LULUCF": "LULUCF"}
emissions_2022 = (
    inventaire.filter(pl.col("annee") == 2022)
    .group_by("code_outil")
    .agg(pl.col("kt_eq_co2").sum())
    .filter(pl.col("kt_eq_co2").abs() > 0.05)
)
defaut = (
    matrice_defaut.filter(pl.col("facteur") > 0)
    .join(inventaire.filter(pl.col("annee") == 2022).select(POLLUTANT="gaz", Source_Code="code_outil").unique(), on=["POLLUTANT", "Source_Code"])
    .with_columns(section=pl.col("activite_outil").map_elements(section_outil, return_dtype=pl.String))
    .group_by("Source_Code", "section")
    .agg(pl.col("facteur").sum())
    .sort("facteur", descending=True)
    .group_by("Source_Code", maintain_order=True)
    .agg(section_defaut=pl.col("section").first(), activites_defaut=pl.col("section").unique().sort().str.join(", "))
    .rename({"Source_Code": "code_outil"})
)
tunisie = (
    matrice.filter(pl.col("annee") == 2022)
    .with_columns(section=pl.col("activite").replace_strict(SECTION_SITE))
    .group_by("code_outil", "prefixe")
    .agg(
        activites_tunisie=pl.when(pl.col("methode").first() == "cle")
        .then(pl.lit("clé ") + pl.col("cle").first())
        .otherwise(pl.col("activite").unique().sort().str.join(", ")),
        section_tunisie=pl.col("section").sort_by("facteur", descending=True).first(),
    )
)
differences = (
    emissions_2022.join(tunisie, on="code_outil", how="left")
    .join(defaut, on="code_outil", how="left")
    .with_columns(
        section_modifiee=pl.when(pl.col("section_defaut") != pl.col("section_tunisie")).then(pl.lit("oui"))
        .when(pl.col("section_defaut").is_null()).then(pl.lit("sans facteur"))
        .otherwise(pl.lit("non")),
        kt_eq_co2_2022=pl.col("kt_eq_co2").round(1),
    )
    .sort("code_outil")
    .select("code_outil", "kt_eq_co2_2022", "section_defaut", "activites_defaut", "section_tunisie", "activites_tunisie", "section_modifiee")
)
with pl.Config(tbl_rows=-1, fmt_str_lengths=60):
    print(differences.filter(pl.col("section_modifiee") != "non"))
print(differences.group_by("section_modifiee").agg(pl.len(), pl.col("kt_eq_co2_2022").sum().round(1)).sort("section_modifiee"))
```

::: {.callout-note}
## Question ouverte
Les choix qui s'écartent de la matrice par défaut sont à valider avec l'INS et l'ANME. Les principaux sont la combustion dans le commerce et les administrations, attribuée aux services et non à la construction ; la combustion résidentielle, attribuée aux ménages ; le transport routier, réparti entre les branches et les ménages au lieu d'aller au transport ; les émissions fugitives du transport et de la distribution du gaz, attribuées à la branche électricité et gaz. Deux points sont propres à l'inventaire tunisien. La catégorie 1.A.1.c.i (fabrication de combustibles solides) porte des émissions importantes et est attribuée à l'extraction d'hydrocarbures avec le reste de 1.A.1.c. La catégorie 1.A.4.b.ii (engins mobiles du secteur résidentiel) porte toute la combustion des ménages, chaque année.
:::
