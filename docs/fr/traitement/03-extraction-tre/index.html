Extraction des tableaux des ressources et des emplois

Les TRE de l’INS de 2015 à 2023 en un seul tableau long

Auteur·rice
Affiliation

Renato Vargas

Consultant du FMI

1 Objet

L’Institut national de la statistique (INS) a transmis les tableaux des ressources et des emplois (TRE) de 2015 à 2023, aux prix courants, en millions de dinars (MDT). Il y a une feuille par année. Les TRE fournissent aux comptes de l’énergie et des émissions la liste des 24 branches d’activité. Les emplois des produits 06, 19 et 35 donnent des clés de répartition de l’énergie entre les branches. La production et la valeur ajoutée par branche servent aux indicateurs d’intensité. Cette page réunit les neuf feuilles dans data/intermediaires/tre.parquet.

Les fonctions sont dans le script scripts/extraire_tre.py1, que cette page importe et exécute.

import sys

import polars as pl

sys.path.insert(0, "scripts")
import extraire_tre as et

et.feuilles()

2 Structure d’une feuille

Chaque feuille juxtapose trois blocs sur les mêmes lignes de produits.

  • Le tableau des ressources : production, importations, impôts et subventions sur les produits, marges, correction CAF/FOB, total des ressources.
  • La matrice de consommation intermédiaire : une colonne par branche, avec le code de la branche en en-tête. Les codes des branches sont ceux des produits.
  • Les emplois finals : consommation finale des ménages et des administrations publiques, formation brute de capital fixe, variation des stocks, exportations.

Sous la matrice, cinq lignes donnent les comptes de production des branches : production, valeur ajoutée, rémunération des salariés, impôts nets sur la production, excédent brut d’exploitation.

Les feuilles de 2015 à 2018 et celles de 2019 à 2023 n’ont pas les mêmes colonnes. Les secondes ont une colonne de libellés de plus et une colonne « Somme des Emplois ». Le script repère donc chaque colonne par le texte de son en-tête, jamais par sa position. La table data/nomenclatures/tre_colonnes.csv associe chaque en-tête à un code du Système de comptabilité nationale et indique les colonnes de sous-total. Un en-tête inconnu arrête la lecture.

3 Format long

Le tableau long a une ligne par année, bloc, ligne et colonne. La colonne ligne contient le code du produit, ou le code de l’agrégat pour les lignes de valeur ajoutée. La colonne colonne contient le code de la branche pour la matrice de consommation intermédiaire et pour les lignes de valeur ajoutée, et le code de l’opération pour les autres colonnes. La colonne agregat signale les sous-totaux publiés, qui servent aux contrôles et ne doivent pas être additionnés aux détails.

tre = et.extraire()
tre.filter(pl.col("annee") == 2022, pl.col("ligne") == "35", ~pl.col("agregat")).sort("valeur", descending=True).head(8)

4 Contrôles

Équilibre des ressources et des emplois. Pour chaque produit et chaque année, le total des ressources publié doit égaler la somme des ressources détaillées et la somme des emplois détaillés.

equilibre = et.ecarts_equilibre(tre)
resume = equilibre.group_by("annee").agg(
    pl.col("ecart_ressources").abs().max().round(3),
    pl.col("ecart_emplois").abs().max().round(3),
).sort("annee")
assert resume["ecart_ressources"].max() < 1 and resume["ecart_emplois"].max() < 1, "TRE déséquilibré"

## Format long

Le tableau long a une ligne par année, bloc, ligne et colonne. La colonne `ligne` contient le code du produit, ou le code de l'agrégat pour les lignes de valeur ajoutée. La colonne `colonne` contient le code de la branche pour la matrice de consommation intermédiaire et pour les lignes de valeur ajoutée, et le code de l'opération pour les autres colonnes. La colonne `agregat` signale les sous-totaux publiés, qui servent aux contrôles et ne doivent pas être additionnés aux détails.

```{python}
#| label: extraction
tre = et.extraire()
tre.filter(pl.col("annee") == 2022, pl.col("ligne") == "35", ~pl.col("agregat")).sort("valeur", descending=True).head(8)
```

## Contrôles

**Équilibre des ressources et des emplois.** Pour chaque produit et chaque année, le total des ressources publié doit égaler la somme des ressources détaillées et la somme des emplois détaillés.

```{python}
#| label: controle-equilibre
equilibre = et.ecarts_equilibre(tre)
resume = equilibre.group_by("annee").agg(
    pl.col("ecart_ressources").abs().max().round(3),
    pl.col("ecart_emplois").abs().max().round(3),
).sort("annee")
assert resume["ecart_ressources"].max() < 1 and resume["ecart_emplois"].max() < 1, "TRE déséquilibré"
resume
```

**Comptes de production.** Pour chaque branche, la production doit égaler la consommation intermédiaire plus la valeur ajoutée.

```{python}
#| label: controle-production
production = et.ecarts_production(tre)
assert production["ecart"].abs().max() < 1, "Compte de production déséquilibré"
production.group_by("annee").agg(pl.col("ecart").abs().max().round(3).alias("ecart_max_mdt")).sort("annee")
```

Les écarts sont inférieurs à un million de dinars et viennent de l'arrondi des valeurs.

## Enregistrement

```{python}
#| label: enregistrement
et.SORTIE.parent.mkdir(parents=True, exist_ok=True)
tre.write_parquet(et.SORTIE, compression="zstd")
```
