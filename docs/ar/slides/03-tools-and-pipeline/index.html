أداتان لصندوق النقد الدولي

PEFA Converter

مصنف إكسل مع دالة Python، هي EB2PEFA، تحول ميزان طاقة بصيغة الوكالة الدولية للطاقة إلى جداول مادية للموارد والاستخدامات، بواسطة مصفوفة توافق (International Monetary Fund, 2024; Pegoue, 2026b).

أداة تحويل حسابات انبعاثات الهواء (I2A)

مصنف إكسل مع دالة Python، هي I2A، تحول جرد غازات الاحتباس الحراري إلى حسابات انبعاثات حسب النشاط، مع تعديل للإقامة من بيانات منظمة التعاون والتنمية في الميدان الاقتصادي (International Monetary Fund, 2026; Pegoue, 2026a).

كيف تعمل الأداتان

من المصنف إلى خط المعالجة

  • الخطوات نفسها، مكتوبة برامج Python مرقمة يمكن لأي شخص قراءتها وتشغيلها.
  • كل خيار توزيع جدول مطابقة مع سببه، لا خلية مخفية.
  • تستدعي البرامج دوال الأداتين دون تعديل وتتوقف إذا اختلفت نتيجتها:
    • PEFA: أكبر فرق 5e-13 بيتاجول؛
    • AEA: أكبر فرق 7e-12 ألف طن مكافئ CO2.
  • أمر واحد يعد كل شيء: uv run python scripts/run_pipeline.py.
