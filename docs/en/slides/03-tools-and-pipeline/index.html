Two IMF tools

PEFA Converter

An Excel workbook with a Python function, EB2PEFA, that turns an energy balance in IEA format into physical supply and use tables, through a concordance matrix (International Monetary Fund, 2024; Pegoue, 2026b).

Air Emissions Account Converter (I2A)

An Excel workbook with a Python function, I2A, that turns a greenhouse gas inventory into air emissions accounts by activity, with a residence adjustment from OECD data (International Monetary Fund, 2026; Pegoue, 2026a).

How the tools work

From workbook to pipeline

  • The same steps, written as numbered Python scripts that anyone can read and run.
  • Every allocation choice is a lookup table with its reason, not a hidden cell.
  • The scripts call the tool functions unchanged and stop if their own result differs:
    • PEFA: largest gap 5e-13 PJ;
    • AEA: largest gap 7e-12 kt CO2 eq.
  • One command compiles everything: uv run python scripts/run_pipeline.py.

The pipeline

Stage Scripts What it does
Extract 01 to 03 Read the balance, the inventory and the supply and use tables
PEFA 10 to 15 IEA template, keys, concordance matrix, tables, checks, Excel
AEA 20 to 24 Inventory, conversion matrix, accounts, bridge, Excel
Report 30 Tables and labels for documents and the data explorer

The pipeline runs in under a minute; the documents only read its outputs.

Outputs

  • Excel workbooks in English, French and Arabic, with the layout of the tool sheets.
  • Tidy tables in CSV and Parquet for analysis.
  • Methods documents and a data explorer that update with every run.
