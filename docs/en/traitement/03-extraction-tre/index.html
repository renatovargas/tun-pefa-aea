Extracting the supply and use tables

The INS supply and use tables from 2015 to 2023 in a single long table

1 Purpose

The National Institute of Statistics (INS) provided the supply and use tables (SUT) from 2015 to 2023, at current prices, in million dinars (million TND). There is one sheet per year. The SUT give the energy and emissions accounts their list of 24 industries. The uses of products 06, 19 and 35 provide keys to allocate energy between industries. Output and value added by industry feed the intensity indicators. This page brings the nine sheets together in data/intermediaires/tre.parquet.

The functions are in the script scripts/extraire_tre.py1, which this page imports and runs.

import sys

import polars as pl

sys.path.insert(0, "scripts")
import extraire_tre as et

et.feuilles()

2 Structure of a sheet

Each sheet places three blocks side by side on the same product rows.

  • The supply table: output, imports, taxes and subsidies on products, margins, CIF/FOB adjustment, total supply.
  • The intermediate consumption matrix: one column per industry, with the industry code as header. Industry codes are the same as product codes.
  • Final uses: final consumption of households and general government, gross fixed capital formation, changes in inventories, exports.

Below the matrix, five rows give the production accounts of the industries: output, value added, compensation of employees, net taxes on production, gross operating surplus.

The sheets for 2015 to 2018 and those for 2019 to 2023 do not have the same columns. The latter have one more label column and a column « Somme des Emplois » (total uses). The script therefore finds each column by the text of its header, never by its position. The table data/nomenclatures/tre_colonnes.csv links each header to a System of National Accounts code and flags the subtotal columns. An unknown header stops the reading.

pl.read_csv("data/nomenclatures/tre_colonnes.csv").select("libelle_source", "code", "bloc", "agregat")

Products and industries are described in data/nomenclatures/tre_produits.csv. Rows CR2 and CR3 are adjustment rows, for the territorial adjustment and the CIF/FOB adjustment.

pl.read_csv("data/nomenclatures/tre_produits.csv", schema_overrides={"code": pl.String}).select("code", "fr", "en")

3 Long format

The long table has one row per year, block, row and column. The column ligne holds the product code, or the aggregate code for the value added rows. The column colonne holds the industry code for the intermediate consumption matrix and the value added rows, and the transaction code for the other columns. The column agregat flags the published subtotals, which serve for checks and must not be added to the details.

tre = et.extraire()
tre.filter(pl.col("annee") == 2022, pl.col("ligne") == "35", ~pl.col("agregat")).sort("valeur", descending=True).head(8)

4 Checks

Supply and use balance. For each product and each year, the published total supply must equal the sum of detailed supply and the sum of detailed uses.

equilibre = et.ecarts_equilibre(tre)
resume = equilibre.group_by("annee").agg(
    pl.col("ecart_ressources").abs().max().round(3),
    pl.col("ecart_emplois").abs().max().round(3),
).sort("annee")
assert resume["ecart_ressources"].max() < 1 and resume["ecart_emplois"].max() < 1, "TRE déséquilibré"
resume

Production accounts. For each industry, output must equal intermediate consumption plus value added.

production = et.ecarts_production(tre)
assert production["ecart"].abs().max() < 1, "Compte de production déséquilibré"
production.group_by("annee").agg(pl.col("ecart").abs().max().round(3).alias("ecart_max_mdt")).sort("annee")

The differences are below one million dinars and come from the rounding of the values.

5 Saving

et.SORTIE.parent.mkdir(parents=True, exist_ok=True)
tre.write_parquet(et.SORTIE, compression="zstd")
print(f"{et.SORTIE} : {tre.height} lignes, {tre['annee'].n_unique()} années")

## Purpose

The National Institute of Statistics (INS) provided the supply and use tables (SUT) from 2015 to 2023, at current prices, in million dinars (million TND). There is one sheet per year. The SUT give the energy and emissions accounts their list of 24 industries. The uses of products 06, 19 and 35 provide keys to allocate energy between industries. Output and value added by industry feed the intensity indicators. This page brings the nine sheets together in `data/intermediaires/tre.parquet`.

The functions are in the script `scripts/extraire_tre.py`[^script], which this page imports and runs.

[^script]: Source code: <https://github.com/renatovargas/tun-pefa-aea/blob/main/scripts/extraire_tre.py>.

```{python}
#| label: parametres
import sys

import polars as pl

sys.path.insert(0, "scripts")
import extraire_tre as et

et.feuilles()
```

## Structure of a sheet

Each sheet places three blocks side by side on the same product rows.

- The supply table: output, imports, taxes and subsidies on products, margins, CIF/FOB adjustment, total supply.
- The intermediate consumption matrix: one column per industry, with the industry code as header. Industry codes are the same as product codes.
- Final uses: final consumption of households and general government, gross fixed capital formation, changes in inventories, exports.

Below the matrix, five rows give the production accounts of the industries: output, value added, compensation of employees, net taxes on production, gross operating surplus.

The sheets for 2015 to 2018 and those for 2019 to 2023 do not have the same columns. The latter have one more label column and a column « Somme des Emplois » (total uses). The script therefore finds each column by the text of its header, never by its position. The table `data/nomenclatures/tre_colonnes.csv` links each header to a System of National Accounts code and flags the subtotal columns. An unknown header stops the reading.

```{python}
#| label: colonnes
pl.read_csv("data/nomenclatures/tre_colonnes.csv").select("libelle_source", "code", "bloc", "agregat")
```

Products and industries are described in `data/nomenclatures/tre_produits.csv`. Rows CR2 and CR3 are adjustment rows, for the territorial adjustment and the CIF/FOB adjustment.

```{python}
#| label: produits
pl.read_csv("data/nomenclatures/tre_produits.csv", schema_overrides={"code": pl.String}).select("code", "fr", "en")
```

## Long format

The long table has one row per year, block, row and column. The column `ligne` holds the product code, or the aggregate code for the value added rows. The column `colonne` holds the industry code for the intermediate consumption matrix and the value added rows, and the transaction code for the other columns. The column `agregat` flags the published subtotals, which serve for checks and must not be added to the details.

```{python}
#| label: extraction
tre = et.extraire()
tre.filter(pl.col("annee") == 2022, pl.col("ligne") == "35", ~pl.col("agregat")).sort("valeur", descending=True).head(8)
```

## Checks

**Supply and use balance.** For each product and each year, the published total supply must equal the sum of detailed supply and the sum of detailed uses.

```{python}
#| label: controle-equilibre
equilibre = et.ecarts_equilibre(tre)
resume = equilibre.group_by("annee").agg(
    pl.col("ecart_ressources").abs().max().round(3),
    pl.col("ecart_emplois").abs().max().round(3),
).sort("annee")
assert resume["ecart_ressources"].max() < 1 and resume["ecart_emplois"].max() < 1, "TRE déséquilibré"
resume
```

**Production accounts.** For each industry, output must equal intermediate consumption plus value added.

```{python}
#| label: controle-production
production = et.ecarts_production(tre)
assert production["ecart"].abs().max() < 1, "Compte de production déséquilibré"
production.group_by("annee").agg(pl.col("ecart").abs().max().round(3).alias("ecart_max_mdt")).sort("annee")
```

The differences are below one million dinars and come from the rounding of the values.

## Saving

```{python}
#| label: enregistrement
et.SORTIE.parent.mkdir(parents=True, exist_ok=True)
tre.write_parquet(et.SORTIE, compression="zstd")
print(f"{et.SORTIE} : {tre.height} lignes, {tre['annee'].n_unique()} années")
```
