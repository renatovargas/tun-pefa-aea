Physical energy supply and use tables

Explicit re-implementation of the PEFA Converter in polars, comparison with the tool, PEFA from 2015 to 2022

1 Purpose

This page computes the physical energy supply and use tables (PEFA) of Tunisia from 2015 to 2022 (United Nations, 2019). It does so in two ways.

The reference layer calls the function EB2PEFA of the IMF PEFA Converter (International Monetary Fund, 2024; Pegoue, 2026), unchanged, through the module scripts/outils_fmi.py1. It gives the same results as the demonstration of the tool in Excel.

The explicit layer redoes each step of EB2PEFA in polars, on this page. It makes the rules applied by the tool visible, and it is the layer that produces the accounts. The code of this layer is adapted from EB2PEFA (Achille Pegoue, IMF); each step refers to the matching lines of PEFA_Converter.py.

Both layers must give the same result. The page compares them on three datasets, the example supplied with the tool, the Tunisian balance with the default concordance matrix, and the Tunisian balance with the Tunisian matrix by industry.

import sys

import polars as pl

sys.path.insert(0, "scripts")
import outils_fmi as of

SORTIE = "data/intermediaires/pefa.parquet"
CLES = ["PEFA_Target_Product_Level1", "PEFA_Target_Product_Level2", "PEFA_Target_Product", "PEFA_Target_Activity", "PEFA_Quadrant"]
TOLERANCE_PJ = 1e-9

plages = of.plages_classeur()
FLUX_MODELE = of.lignes_flux_modele()
PRODUITS_MODELE = [p for p in of.produits_modele() if p != "Total"]
modele = pl.read_parquet("data/intermediaires/bilan_modele_fmi.parquet")
concordance_tunisie = pl.read_parquet("data/intermediaires/concordance_tunisie.parquet")

2 The explicit layer

2.1 Flow levels

The tool finds the blocks of the balance from the position of the titles in the template (lines 70 to 208 of PEFA_Converter.py). Each flow receives a level 1 (supply, other flows, transformation, energy industry, losses, final consumption) and, within final consumption, a level 2 (industry, transport, other, non-energy use). Title and total rows have no level and are not used.

TITRES = {
    "Transformation processes": ("Transformation processes", None),
    "Energy industry own use": ("Energy industry own use", None),
    "Industry": ("Total final consumption", "Industry"),
    "Transport": ("Total final consumption", "Transport"),
    "Other": ("Total final consumption", "Other"),
    "Non-energy use": ("Total final consumption", "Non-energy use"),
    "Electricity output (GWh)": ("Electricity output (GWh)", None),
}


def niveaux_flux(flux: list[str]) -> pl.DataFrame:
    """Niveaux 1 et 2 de chaque flux du modèle, selon les règles de position de EB2PEFA."""
    lignes, etat = [], ("Total primary energy supply", None)
    for f in flux:
        if f == "Total primary energy supply":
            lignes.append((f, None, None))
            etat = ("Other flows", None)
        elif f in TITRES or f in ("Total final consumption", "Heat output"):
            lignes.append((f, None, None))
            etat = TITRES.get(f, (None, None))
        elif f == "Losses":
            lignes.append((f, "Losses", None))
        else:
            lignes.append((f, *etat))
    return pl.DataFrame(lignes, schema=["EB_Flow", "EB_Flow_Level1", "EB_Flow_Level2"], orient="row")


NIVEAUX = niveaux_flux(FLUX_MODELE)
NIVEAUX.group_by("EB_Flow_Level1", "EB_Flow_Level2", maintain_order=True).agg(pl.len().alias("flux"))

2.2 Preparing the balance and the matrix

The balance is put in long format; zero cells are dropped. Non-energy use in chemicals, given as a memo item, is subtracted from the industry non-energy use row (lines 459 to 477). Exports and stock changes change sign (lines 481 and 482).

The matrix loses its rows with a zero factor. Its factors are rescaled to a sum of 1 per flow, product, target product and quadrant (lines 220 to 256).

CLES_FLUX = ["EB_Flow_Level1", "EB_Flow_Level2", "EB_Flow", "EB_Product"]
MEMO = "   Memo: Non-energy use chemical/petrochemical"
INDUSTRIE_NE = "Non-energy use industry/transformation/energy"


def preparer_bilan(bilan: pl.DataFrame) -> pl.DataFrame:
    """Bilan long (EB_Flow, EB_Product, Energy en TJ) avec niveaux, mémo retranché et signes de l'outil."""
    long = bilan.group_by("EB_Flow", "EB_Product").agg(pl.col("Energy").sum()).filter(pl.col("Energy") != 0)
    memo = long.filter(pl.col("EB_Flow") == MEMO).select("EB_Product", pl.col("Energy").alias("memo"))
    long = (
        long.join(memo, on="EB_Product", how="left")
        .with_columns(
            Energy=pl.when(pl.col("EB_Flow") == INDUSTRIE_NE).then(pl.col("Energy") - pl.col("memo").fill_null(0)).otherwise("Energy")
        )
        .drop("memo")
        .with_columns(
            Energy=pl.when(pl.col("EB_Flow").is_in(["Exports", "Stock changes"])).then(-pl.col("Energy")).otherwise("Energy")
        )
    )
    return long.join(NIVEAUX, on="EB_Flow").filter(pl.col("EB_Flow_Level1").is_not_null())


def preparer_matrice(matrice: pl.DataFrame) -> pl.DataFrame:
    """Matrice sans facteurs nuls, sans doublons, facteurs normalisés par flux, produit, produit cible et quadrant."""
    groupe = CLES_FLUX + ["PEFA_Target_Product", "PEFA_Target_Product_Level1", "PEFA_Target_Product_Level2", "PEFA_Quadrant"]
    return (
        matrice.filter(pl.col("Allocation Factor") != 0)
        .group_by(groupe + ["EB_Category", "PEFA_Target_Activity"])
        .agg(pl.col("Allocation Factor").sum())
        .with_columns(pl.col("Allocation Factor") / pl.col("Allocation Factor").sum().over(groupe))
    )

2.3 Natural inputs, transfers and statistical difference

Primary production is a supply of the energy product by the activity that produces it. It is duplicated as a use of natural inputs by that activity, and as a supply of natural inputs by the environment (lines 500 to 547). Renewable sources, according to the product classification of the tool, become « inputs of energy from renewable sources ».

Transfers are duplicated as a use of residuals and a supply by accumulation (lines 563 to 578). The statistical difference factors are normalised by flow and product, then change sign (lines 582 to 603).

def regles_amont(cm: pl.DataFrame, renouvelables: list[str], dechets: list[str]) -> pl.DataFrame:
    """Ajoute à la matrice les lignes de ressources naturelles, de transferts et d'écart statistique."""
    tpes = pl.col("EB_Flow_Level1") == "Total primary energy supply"
    production = cm.filter(tpes & (pl.col("EB_Flow") == "Production")).with_columns(
        pl.when(pl.col("PEFA_Target_Activity") == "Acc").then(-pl.col("Allocation Factor")).otherwise(pl.col("Allocation Factor")).alias("Allocation Factor")
    )
    naturels = production.filter(~pl.col("PEFA_Target_Activity").is_in(["Acc", "RoW"])).with_columns(
        PEFA_Quadrant=pl.lit("Use"),
        PEFA_Target_Product_Level1=pl.when(pl.col("EB_Product").is_in(dechets)).then(pl.lit("Other residual flows:")).otherwise(pl.lit("Energy from natural inputs:")),
        PEFA_Target_Product_Level2=pl.lit(None, pl.String),
        PEFA_Target_Product=pl.when(pl.col("EB_Product").is_in(dechets)).then(pl.lit("Energy from solid waste"))
        .when(pl.col("EB_Product").is_in(renouvelables)).then(pl.lit("Inputs of energy from renewable sources"))
        .otherwise(pl.lit("Natural resource inputs")),
    )
    environnement = naturels.with_columns(
        PEFA_Quadrant=pl.lit("Supply"),
        PEFA_Target_Activity=pl.when(pl.col("EB_Product").is_in(dechets)).then(pl.lit("Acc")).otherwise(pl.lit("Env")),
    )

    transferts = cm.filter((pl.col("EB_Flow_Level1") == "Other flows") & (pl.col("EB_Flow") == "Transfers"))
    residus = transferts.with_columns(
        PEFA_Target_Product_Level1=pl.lit("Other residual flows:"),
        PEFA_Target_Product_Level2=pl.lit(None, pl.String),
        PEFA_Target_Product=pl.lit("Energy from solid waste"),
        PEFA_Quadrant=pl.lit("Use"),
    )
    accumulation = residus.with_columns(PEFA_Quadrant=pl.lit("Supply"), PEFA_Target_Activity=pl.lit("Acc"))

    ecart = cm.filter((pl.col("EB_Flow_Level1") == "Other flows") & (pl.col("EB_Flow") == "Statistical differences"))
    ecart = ecart.with_columns(
        -(pl.col("Allocation Factor") / pl.col("Allocation Factor").sum().over(CLES_FLUX)).alias("Allocation Factor")
    )
    # Résidus de l'écart statistique attribué à une branche (lignes 606 à 621) : absent si l'écart va à l'accumulation.
    ecart_branches = ecart.filter(~pl.col("PEFA_Target_Activity").is_in(["Acc", "RoW"]))
    ecart_residus = ecart_branches.with_columns(
        PEFA_Target_Product_Level1=pl.lit("Energy residuals:"),
        PEFA_Target_Product_Level2=pl.lit(None, pl.String),
        PEFA_Target_Product=pl.lit("Energy residuals from end-use"),
        PEFA_Quadrant=pl.lit("Supply"),
    )
    ecart_environnement = ecart_residus.with_columns(PEFA_Quadrant=pl.lit("Use"), PEFA_Target_Activity=pl.lit("Env"))

    reste = cm.filter(
        ~(tpes & (pl.col("EB_Flow") == "Production"))
        & ~((pl.col("EB_Flow_Level1") == "Other flows") & (pl.col("EB_Flow") == "Statistical differences"))
    )
    return pl.concat(
        [reste, production, naturels, environnement, residus, accumulation, ecart, ecart_residus, ecart_environnement],
        how="vertical_relaxed",
    )

2.4 Downstream uses, outputs and residuals

The balance and the matrix are joined; the energy of each row is the energy of the balance multiplied by the factor, divided by 1,000 to go from TJ to PJ (lines 626 to 631).

The downstream flows then receive their signs (lines 636 to 702). Transformation outputs, positive in the balance, become supplies of energy products; inputs, which are negative, become uses. Energy industry own use, losses and bunkers become positive uses. Each downstream flow is duplicated as residuals (lines 713 to 754). The activity supplies energy residuals, which go to the environment. For transformation and losses, these are residuals from losses, equal to inputs minus outputs. For consumption, they are residuals from end use. Non-energy uses supply non-energy residuals, which go to accumulation.

AVAL = ["Transformation processes", "Energy industry own use", "Losses", "Total final consumption", "Electricity output (GWh)", "Heat output"]
SOUTES = ["International marine bunkers", "International aviation bunkers"]


def regles_aval(pefa: pl.DataFrame) -> pl.DataFrame:
    """Signes des flux en aval et résidus d'énergie correspondants."""
    niveau1, flux, energie = pl.col("EB_Flow_Level1"), pl.col("EB_Flow"), pl.col("PEFA_Energy")
    tpes = niveau1 == "Total primary energy supply"
    est_aval = niveau1.is_in(AVAL) | (tpes & flux.is_in(SOUTES))
    amont, aval = pefa.filter(~est_aval), pefa.filter(est_aval)

    transformation = niveau1 == "Transformation processes"
    signes = aval.with_columns(
        PEFA_Quadrant=pl.when((energie > 0) & (transformation | tpes)).then(pl.lit("Supply")).otherwise("PEFA_Quadrant"),
        PEFA_Target_Product_Level2=pl.when((energie > 0) & transformation).then(pl.lit("Production of energy products by SIEC class:")).otherwise("PEFA_Target_Product_Level2"),
        PEFA_Energy=pl.when(transformation | tpes).then(energie.abs())
        .when(niveau1.is_in(["Energy industry own use", "Losses"])).then(-energie)
        .otherwise(energie),
    )

    non_energetique = (niveau1 == "Total final consumption") & (pl.col("EB_Flow_Level2") == "Non-energy use")
    fin_usage = (niveau1.is_in(["Energy industry own use", "Losses", "Total final consumption"]) & (flux != "Losses")) | (tpes & flux.is_in(SOUTES))
    residus = aval.with_columns(
        PEFA_Energy=pl.when(niveau1.is_in(["Transformation processes", "Energy industry own use", "Losses"])).then(-energie)
        .when(tpes).then(energie.abs())
        .otherwise(energie),
        PEFA_Target_Product_Level1=pl.when(non_energetique).then(pl.lit("Other residual flows:")).otherwise(pl.lit("Energy residuals:")),
        PEFA_Target_Product_Level2=pl.lit(None, pl.String),
        PEFA_Target_Product=pl.when(non_energetique).then(pl.lit("Residuals from end-use for non-energy purposes"))
        .when(fin_usage).then(pl.lit("Energy residuals from end-use"))
        .otherwise(pl.lit("Energy residuals from losses")),
        PEFA_Quadrant=pl.lit("Supply"),
    )
    absorption = residus.with_columns(
        PEFA_Quadrant=pl.lit("Use"),
        PEFA_Target_Activity=pl.when(non_energetique).then(pl.lit("Acc")).otherwise(pl.lit("Env")),
    )
    return pl.concat([amont, signes, residus, absorption])

2.5 Assembly

The full function chains the steps. The statistical difference is taken out of the main table and shown on a separate row, with the activity « Statistical differences » (lines 766 to 785), as the tool does with its default filter.

def pefa_explicite(bilan: pl.DataFrame, matrice: pl.DataFrame, classification: pl.DataFrame) -> pl.DataFrame:
    """Reprise de EB2PEFA. bilan : EB_Flow, EB_Product, Energy (TJ). Résultat en PJ, comme l'outil."""
    renouvelables = classification.filter(pl.col("Group") == "Renewable")["EB_Product"].to_list()
    dechets = classification.filter(pl.col("Group") == "Waste")["EB_Product"].to_list()
    cm = regles_amont(preparer_matrice(matrice), renouvelables, dechets)
    eb = preparer_bilan(bilan)
    jointure = eb.join(cm, on=CLES_FLUX, nulls_equal=True).with_columns(
        PEFA_Energy=pl.col("Energy") * pl.col("Allocation Factor") / 1000
    )
    pefa = regles_aval(jointure)
    ecart = pefa.filter(pl.col("EB_Flow") == "Statistical differences").with_columns(
        PEFA_Target_Activity=pl.lit("Statistical differences")
    )
    principal = pefa.filter(pl.col("EB_Flow") != "Statistical differences")
    return pl.concat(
        [t.group_by(CLES).agg(pl.col("PEFA_Energy").sum()) for t in (principal, ecart)]
    )


def comparer(outil: pl.DataFrame, explicite: pl.DataFrame) -> pl.DataFrame:
    """Écarts entre l'outil et la couche explicite, cellule par cellule (PJ)."""
    a = outil.group_by(CLES).agg(pl.col("PEFA_Energy").sum().alias("outil"))
    b = explicite.group_by(CLES).agg(pl.col("PEFA_Energy").sum().alias("explicite"))
    return (
        a.join(b, on=CLES, how="full", coalesce=True, nulls_equal=True)
        .with_columns(pl.col("outil", "explicite").fill_null(0))
        .with_columns(ecart=pl.col("outil") - pl.col("explicite"))
    )

3 Check on the tool example

The tool workbook contains an example balance. The workbook range Energy_Balance includes the « Total » column. The default matrix has rows for this product in the four non-energy flows, so the tool counts non-energy use twice, once by product and once through the total. With the « Total » column, supply and use of the example are not equal; without it, they are. The Tunisian accounts are therefore computed without the « Total » column.

classification = pl.DataFrame(plages["EB_Product"][1:], schema=plages["EB_Product"][0], orient="row")
matrice_defaut = pl.DataFrame(plages["CM"][1:], schema=[str(c) for c in plages["CM"][0]], orient="row", infer_schema_length=None).with_columns(
    pl.col("Allocation Factor").cast(pl.Float64, strict=False).fill_null(0)
)


def sans_total(plage: list[list]) -> list[list]:
    """Retire la colonne « Total » d'une plage Energy_Balance."""
    j = plage[0].index("Total")
    return [ligne[:j] + ligne[j + 1 :] for ligne in plage]


def plage_en_long(plage: list[list]) -> pl.DataFrame:
    """Plage Energy_Balance en format long ; les textes (« x ») valent 0, comme dans l'outil."""
    produits = plage[0][1:]
    lignes = [
        (ligne[0], p, v if isinstance(v, float) else 0.0)
        for ligne in plage[1:] if ligne[0] is not None
        for p, v in zip(produits, ligne[1:])
    ]
    return pl.DataFrame(lignes, schema=["EB_Flow", "EB_Product", "Energy"], orient="row")


def equilibre(pefa: pl.DataFrame) -> dict:
    """Total des ressources et des emplois (PJ)."""
    return {q: round(pefa.filter(pl.col("PEFA_Quadrant") == q)["PEFA_Energy"].sum(), 3) for q in ["Supply", "Use"]}


args = (plages["EB_Bridging_Items"], plages["EB_Product"], of.FILTRE_DEFAUT)
avec = of.eb2pefa(plages["EB"], plages["CM"], *args)
eb_exemple = sans_total(plages["EB"])
outil_exemple = of.eb2pefa(eb_exemple, plages["CM"], *args)
explicite_exemple = pefa_explicite(plage_en_long(eb_exemple), matrice_defaut, classification)
ecarts = comparer(outil_exemple, explicite_exemple)
assert ecarts["ecart"].abs().max() < TOLERANCE_PJ
print(f"Avec la colonne Total : {equilibre(avec)}")
print(f"Sans la colonne Total : {equilibre(outil_exemple)}")
print(f"Couche explicite : {ecarts.height} cellules, écart maximal avec l'outil {ecarts['ecart'].abs().max():.2e} PJ")

4 Accounts for Tunisia

4.1 With the default matrix

For each year, the reference layer receives the balance transferred into the template (page 10) and the default matrix of the tool. The explicit layer receives the same data.

ANNEES = sorted(modele["annee"].unique().to_list())


def bilan_annee(annee: int) -> pl.DataFrame:
    return modele.filter(pl.col("annee") == annee).select(
        pl.col("flux_modele").alias("EB_Flow"), pl.col("produit_modele").alias("EB_Product"), pl.col("tj").alias("Energy")
    )


def plage_annee(annee: int) -> list[list]:
    return of.bilan_vers_plage(modele.filter(pl.col("annee") == annee), FLUX_MODELE, PRODUITS_MODELE)


def matrice_en_plage(matrice: pl.DataFrame) -> list[list]:
    """Matrice polars en plage Excel : en-tête puis lignes, cellules vides à None."""
    colonnes = [str(c) for c in plages["CM"][0]]
    return [colonnes] + [list(r) for r in matrice.select(colonnes).iter_rows()]


def deux_couches(annee: int, matrice: pl.DataFrame) -> tuple[pl.DataFrame, pl.DataFrame]:
    outil = of.eb2pefa(plage_annee(annee), matrice_en_plage(matrice), *args).with_columns(annee=pl.lit(annee, pl.Int16))
    explicite = pefa_explicite(bilan_annee(annee), matrice, classification).with_columns(annee=pl.lit(annee, pl.Int16))
    return outil, explicite


def resume_comparaison(resultats: dict) -> pl.DataFrame:
    lignes = []
    for annee, (outil, explicite) in resultats.items():
        ecarts = comparer(outil.drop("annee"), explicite.drop("annee"))
        lignes.append({
            "annee": annee, "cellules": ecarts.height, "ecart_max_pj": ecarts["ecart"].abs().max(),
            "ressources_pj": equilibre(explicite)["Supply"], "emplois_pj": equilibre(explicite)["Use"],
        })
    return pl.DataFrame(lignes).with_columns(
        ressources_moins_emplois_ktep=((pl.col("ressources_pj") - pl.col("emplois_pj")) * 1000 / 41.868).round(1)
    )


resultats_defaut = {a: deux_couches(a, matrice_defaut) for a in ANNEES}
resume_defaut = resume_comparaison(resultats_defaut)
assert resume_defaut["ecart_max_pj"].max() < TOLERANCE_PJ
resume_defaut

The Tunisian matrix (page 12) assigns energy to the 24 SUT industries and to households. The tool accepts these activity codes unchanged, because it treats only the pseudo-activities « RoW », « Acc » and « Env » separately. The two layers are therefore compared at industry level.

resultats = {
    a: deux_couches(a, concordance_tunisie.filter(pl.col("annee") == a).drop("annee"))
    for a in ANNEES
}
resume = resume_comparaison(resultats)

resume

The statistical difference appears in uses, on its separate row, with the IEA sign. Total supply and total use still differ by a few ktoe, as the last column shows. This difference comes from the rounding of the cells of the published balance, already noted in the identity check of page 10. The balance check by product is done on the next page.

## Purpose

This page computes the physical energy supply and use tables (PEFA) of Tunisia from 2015 to 2022 [@seeaenergy2019]. It does so in two ways.

The **reference layer** calls the function `EB2PEFA` of the IMF PEFA Converter [@pegoue2026pefa; @imf2024pefa], unchanged, through the module `scripts/outils_fmi.py`[^outils]. It gives the same results as the demonstration of the tool in Excel.

The **explicit layer** redoes each step of `EB2PEFA` in polars, on this page. It makes the rules applied by the tool visible, and it is the layer that produces the accounts. The code of this layer is adapted from `EB2PEFA` (Achille Pegoue, IMF); each step refers to the matching lines of `PEFA_Converter.py`.

Both layers must give the same result. The page compares them on three datasets, the example supplied with the tool, the Tunisian balance with the default concordance matrix, and the Tunisian balance with the Tunisian matrix by industry.

[^outils]: Source code: <https://github.com/renatovargas/tun-pefa-aea/blob/main/scripts/outils_fmi.py>. Tool: <https://github.com/renatovargas/tun-pefa-aea/tree/main/outils-fmi/pefa-converter>.

## The explicit layer

### Flow levels

The tool finds the blocks of the balance from the position of the titles in the template (lines 70 to 208 of `PEFA_Converter.py`). Each flow receives a level 1 (supply, other flows, transformation, energy industry, losses, final consumption) and, within final consumption, a level 2 (industry, transport, other, non-energy use). Title and total rows have no level and are not used.

```{python}
#| label: niveaux
TITRES = {
    "Transformation processes": ("Transformation processes", None),
    "Energy industry own use": ("Energy industry own use", None),
    "Industry": ("Total final consumption", "Industry"),
    "Transport": ("Total final consumption", "Transport"),
    "Other": ("Total final consumption", "Other"),
    "Non-energy use": ("Total final consumption", "Non-energy use"),
    "Electricity output (GWh)": ("Electricity output (GWh)", None),
}


def niveaux_flux(flux: list[str]) -> pl.DataFrame:
    """Niveaux 1 et 2 de chaque flux du modèle, selon les règles de position de EB2PEFA."""
    lignes, etat = [], ("Total primary energy supply", None)
    for f in flux:
        if f == "Total primary energy supply":
            lignes.append((f, None, None))
            etat = ("Other flows", None)
        elif f in TITRES or f in ("Total final consumption", "Heat output"):
            lignes.append((f, None, None))
            etat = TITRES.get(f, (None, None))
        elif f == "Losses":
            lignes.append((f, "Losses", None))
        else:
            lignes.append((f, *etat))
    return pl.DataFrame(lignes, schema=["EB_Flow", "EB_Flow_Level1", "EB_Flow_Level2"], orient="row")


NIVEAUX = niveaux_flux(FLUX_MODELE)
NIVEAUX.group_by("EB_Flow_Level1", "EB_Flow_Level2", maintain_order=True).agg(pl.len().alias("flux"))
```

### Preparing the balance and the matrix

The balance is put in long format; zero cells are dropped. Non-energy use in chemicals, given as a memo item, is subtracted from the industry non-energy use row (lines 459 to 477). Exports and stock changes change sign (lines 481 and 482).

The matrix loses its rows with a zero factor. Its factors are rescaled to a sum of 1 per flow, product, target product and quadrant (lines 220 to 256).

```{python}
#| label: preparation
CLES_FLUX = ["EB_Flow_Level1", "EB_Flow_Level2", "EB_Flow", "EB_Product"]
MEMO = "   Memo: Non-energy use chemical/petrochemical"
INDUSTRIE_NE = "Non-energy use industry/transformation/energy"


def preparer_bilan(bilan: pl.DataFrame) -> pl.DataFrame:
    """Bilan long (EB_Flow, EB_Product, Energy en TJ) avec niveaux, mémo retranché et signes de l'outil."""
    long = bilan.group_by("EB_Flow", "EB_Product").agg(pl.col("Energy").sum()).filter(pl.col("Energy") != 0)
    memo = long.filter(pl.col("EB_Flow") == MEMO).select("EB_Product", pl.col("Energy").alias("memo"))
    long = (
        long.join(memo, on="EB_Product", how="left")
        .with_columns(
            Energy=pl.when(pl.col("EB_Flow") == INDUSTRIE_NE).then(pl.col("Energy") - pl.col("memo").fill_null(0)).otherwise("Energy")
        )
        .drop("memo")
        .with_columns(
            Energy=pl.when(pl.col("EB_Flow").is_in(["Exports", "Stock changes"])).then(-pl.col("Energy")).otherwise("Energy")
        )
    )
    return long.join(NIVEAUX, on="EB_Flow").filter(pl.col("EB_Flow_Level1").is_not_null())


def preparer_matrice(matrice: pl.DataFrame) -> pl.DataFrame:
    """Matrice sans facteurs nuls, sans doublons, facteurs normalisés par flux, produit, produit cible et quadrant."""
    groupe = CLES_FLUX + ["PEFA_Target_Product", "PEFA_Target_Product_Level1", "PEFA_Target_Product_Level2", "PEFA_Quadrant"]
    return (
        matrice.filter(pl.col("Allocation Factor") != 0)
        .group_by(groupe + ["EB_Category", "PEFA_Target_Activity"])
        .agg(pl.col("Allocation Factor").sum())
        .with_columns(pl.col("Allocation Factor") / pl.col("Allocation Factor").sum().over(groupe))
    )
```

### Natural inputs, transfers and statistical difference

Primary production is a supply of the energy product by the activity that produces it. It is duplicated as a use of natural inputs by that activity, and as a supply of natural inputs by the environment (lines 500 to 547). Renewable sources, according to the product classification of the tool, become « inputs of energy from renewable sources ».

Transfers are duplicated as a use of residuals and a supply by accumulation (lines 563 to 578). The statistical difference factors are normalised by flow and product, then change sign (lines 582 to 603).

```{python}
#| label: regles-amont
def regles_amont(cm: pl.DataFrame, renouvelables: list[str], dechets: list[str]) -> pl.DataFrame:
    """Ajoute à la matrice les lignes de ressources naturelles, de transferts et d'écart statistique."""
    tpes = pl.col("EB_Flow_Level1") == "Total primary energy supply"
    production = cm.filter(tpes & (pl.col("EB_Flow") == "Production")).with_columns(
        pl.when(pl.col("PEFA_Target_Activity") == "Acc").then(-pl.col("Allocation Factor")).otherwise(pl.col("Allocation Factor")).alias("Allocation Factor")
    )
    naturels = production.filter(~pl.col("PEFA_Target_Activity").is_in(["Acc", "RoW"])).with_columns(
        PEFA_Quadrant=pl.lit("Use"),
        PEFA_Target_Product_Level1=pl.when(pl.col("EB_Product").is_in(dechets)).then(pl.lit("Other residual flows:")).otherwise(pl.lit("Energy from natural inputs:")),
        PEFA_Target_Product_Level2=pl.lit(None, pl.String),
        PEFA_Target_Product=pl.when(pl.col("EB_Product").is_in(dechets)).then(pl.lit("Energy from solid waste"))
        .when(pl.col("EB_Product").is_in(renouvelables)).then(pl.lit("Inputs of energy from renewable sources"))
        .otherwise(pl.lit("Natural resource inputs")),
    )
    environnement = naturels.with_columns(
        PEFA_Quadrant=pl.lit("Supply"),
        PEFA_Target_Activity=pl.when(pl.col("EB_Product").is_in(dechets)).then(pl.lit("Acc")).otherwise(pl.lit("Env")),
    )

    transferts = cm.filter((pl.col("EB_Flow_Level1") == "Other flows") & (pl.col("EB_Flow") == "Transfers"))
    residus = transferts.with_columns(
        PEFA_Target_Product_Level1=pl.lit("Other residual flows:"),
        PEFA_Target_Product_Level2=pl.lit(None, pl.String),
        PEFA_Target_Product=pl.lit("Energy from solid waste"),
        PEFA_Quadrant=pl.lit("Use"),
    )
    accumulation = residus.with_columns(PEFA_Quadrant=pl.lit("Supply"), PEFA_Target_Activity=pl.lit("Acc"))

    ecart = cm.filter((pl.col("EB_Flow_Level1") == "Other flows") & (pl.col("EB_Flow") == "Statistical differences"))
    ecart = ecart.with_columns(
        -(pl.col("Allocation Factor") / pl.col("Allocation Factor").sum().over(CLES_FLUX)).alias("Allocation Factor")
    )
    # Résidus de l'écart statistique attribué à une branche (lignes 606 à 621) : absent si l'écart va à l'accumulation.
    ecart_branches = ecart.filter(~pl.col("PEFA_Target_Activity").is_in(["Acc", "RoW"]))
    ecart_residus = ecart_branches.with_columns(
        PEFA_Target_Product_Level1=pl.lit("Energy residuals:"),
        PEFA_Target_Product_Level2=pl.lit(None, pl.String),
        PEFA_Target_Product=pl.lit("Energy residuals from end-use"),
        PEFA_Quadrant=pl.lit("Supply"),
    )
    ecart_environnement = ecart_residus.with_columns(PEFA_Quadrant=pl.lit("Use"), PEFA_Target_Activity=pl.lit("Env"))

    reste = cm.filter(
        ~(tpes & (pl.col("EB_Flow") == "Production"))
        & ~((pl.col("EB_Flow_Level1") == "Other flows") & (pl.col("EB_Flow") == "Statistical differences"))
    )
    return pl.concat(
        [reste, production, naturels, environnement, residus, accumulation, ecart, ecart_residus, ecart_environnement],
        how="vertical_relaxed",
    )
```

### Downstream uses, outputs and residuals

The balance and the matrix are joined; the energy of each row is the energy of the balance multiplied by the factor, divided by 1,000 to go from TJ to PJ (lines 626 to 631).

The downstream flows then receive their signs (lines 636 to 702). Transformation outputs, positive in the balance, become supplies of energy products; inputs, which are negative, become uses. Energy industry own use, losses and bunkers become positive uses. Each downstream flow is duplicated as residuals (lines 713 to 754). The activity supplies energy residuals, which go to the environment. For transformation and losses, these are residuals from losses, equal to inputs minus outputs. For consumption, they are residuals from end use. Non-energy uses supply non-energy residuals, which go to accumulation.

```{python}
#| label: aval
AVAL = ["Transformation processes", "Energy industry own use", "Losses", "Total final consumption", "Electricity output (GWh)", "Heat output"]
SOUTES = ["International marine bunkers", "International aviation bunkers"]


def regles_aval(pefa: pl.DataFrame) -> pl.DataFrame:
    """Signes des flux en aval et résidus d'énergie correspondants."""
    niveau1, flux, energie = pl.col("EB_Flow_Level1"), pl.col("EB_Flow"), pl.col("PEFA_Energy")
    tpes = niveau1 == "Total primary energy supply"
    est_aval = niveau1.is_in(AVAL) | (tpes & flux.is_in(SOUTES))
    amont, aval = pefa.filter(~est_aval), pefa.filter(est_aval)

    transformation = niveau1 == "Transformation processes"
    signes = aval.with_columns(
        PEFA_Quadrant=pl.when((energie > 0) & (transformation | tpes)).then(pl.lit("Supply")).otherwise("PEFA_Quadrant"),
        PEFA_Target_Product_Level2=pl.when((energie > 0) & transformation).then(pl.lit("Production of energy products by SIEC class:")).otherwise("PEFA_Target_Product_Level2"),
        PEFA_Energy=pl.when(transformation | tpes).then(energie.abs())
        .when(niveau1.is_in(["Energy industry own use", "Losses"])).then(-energie)
        .otherwise(energie),
    )

    non_energetique = (niveau1 == "Total final consumption") & (pl.col("EB_Flow_Level2") == "Non-energy use")
    fin_usage = (niveau1.is_in(["Energy industry own use", "Losses", "Total final consumption"]) & (flux != "Losses")) | (tpes & flux.is_in(SOUTES))
    residus = aval.with_columns(
        PEFA_Energy=pl.when(niveau1.is_in(["Transformation processes", "Energy industry own use", "Losses"])).then(-energie)
        .when(tpes).then(energie.abs())
        .otherwise(energie),
        PEFA_Target_Product_Level1=pl.when(non_energetique).then(pl.lit("Other residual flows:")).otherwise(pl.lit("Energy residuals:")),
        PEFA_Target_Product_Level2=pl.lit(None, pl.String),
        PEFA_Target_Product=pl.when(non_energetique).then(pl.lit("Residuals from end-use for non-energy purposes"))
        .when(fin_usage).then(pl.lit("Energy residuals from end-use"))
        .otherwise(pl.lit("Energy residuals from losses")),
        PEFA_Quadrant=pl.lit("Supply"),
    )
    absorption = residus.with_columns(
        PEFA_Quadrant=pl.lit("Use"),
        PEFA_Target_Activity=pl.when(non_energetique).then(pl.lit("Acc")).otherwise(pl.lit("Env")),
    )
    return pl.concat([amont, signes, residus, absorption])
```

### Assembly

The full function chains the steps. The statistical difference is taken out of the main table and shown on a separate row, with the activity « Statistical differences » (lines 766 to 785), as the tool does with its default filter.

```{python}
#| label: assemblage
def pefa_explicite(bilan: pl.DataFrame, matrice: pl.DataFrame, classification: pl.DataFrame) -> pl.DataFrame:
    """Reprise de EB2PEFA. bilan : EB_Flow, EB_Product, Energy (TJ). Résultat en PJ, comme l'outil."""
    renouvelables = classification.filter(pl.col("Group") == "Renewable")["EB_Product"].to_list()
    dechets = classification.filter(pl.col("Group") == "Waste")["EB_Product"].to_list()
    cm = regles_amont(preparer_matrice(matrice), renouvelables, dechets)
    eb = preparer_bilan(bilan)
    jointure = eb.join(cm, on=CLES_FLUX, nulls_equal=True).with_columns(
        PEFA_Energy=pl.col("Energy") * pl.col("Allocation Factor") / 1000
    )
    pefa = regles_aval(jointure)
    ecart = pefa.filter(pl.col("EB_Flow") == "Statistical differences").with_columns(
        PEFA_Target_Activity=pl.lit("Statistical differences")
    )
    principal = pefa.filter(pl.col("EB_Flow") != "Statistical differences")
    return pl.concat(
        [t.group_by(CLES).agg(pl.col("PEFA_Energy").sum()) for t in (principal, ecart)]
    )


def comparer(outil: pl.DataFrame, explicite: pl.DataFrame) -> pl.DataFrame:
    """Écarts entre l'outil et la couche explicite, cellule par cellule (PJ)."""
    a = outil.group_by(CLES).agg(pl.col("PEFA_Energy").sum().alias("outil"))
    b = explicite.group_by(CLES).agg(pl.col("PEFA_Energy").sum().alias("explicite"))
    return (
        a.join(b, on=CLES, how="full", coalesce=True, nulls_equal=True)
        .with_columns(pl.col("outil", "explicite").fill_null(0))
        .with_columns(ecart=pl.col("outil") - pl.col("explicite"))
    )
```

## Check on the tool example

The tool workbook contains an example balance. The workbook range `Energy_Balance` includes the « Total » column. The default matrix has rows for this product in the four non-energy flows, so the tool counts non-energy use twice, once by product and once through the total. With the « Total » column, supply and use of the example are not equal; without it, they are. The Tunisian accounts are therefore computed without the « Total » column.

```{python}
#| label: exemple
classification = pl.DataFrame(plages["EB_Product"][1:], schema=plages["EB_Product"][0], orient="row")
matrice_defaut = pl.DataFrame(plages["CM"][1:], schema=[str(c) for c in plages["CM"][0]], orient="row", infer_schema_length=None).with_columns(
    pl.col("Allocation Factor").cast(pl.Float64, strict=False).fill_null(0)
)


def sans_total(plage: list[list]) -> list[list]:
    """Retire la colonne « Total » d'une plage Energy_Balance."""
    j = plage[0].index("Total")
    return [ligne[:j] + ligne[j + 1 :] for ligne in plage]


def plage_en_long(plage: list[list]) -> pl.DataFrame:
    """Plage Energy_Balance en format long ; les textes (« x ») valent 0, comme dans l'outil."""
    produits = plage[0][1:]
    lignes = [
        (ligne[0], p, v if isinstance(v, float) else 0.0)
        for ligne in plage[1:] if ligne[0] is not None
        for p, v in zip(produits, ligne[1:])
    ]
    return pl.DataFrame(lignes, schema=["EB_Flow", "EB_Product", "Energy"], orient="row")


def equilibre(pefa: pl.DataFrame) -> dict:
    """Total des ressources et des emplois (PJ)."""
    return {q: round(pefa.filter(pl.col("PEFA_Quadrant") == q)["PEFA_Energy"].sum(), 3) for q in ["Supply", "Use"]}


args = (plages["EB_Bridging_Items"], plages["EB_Product"], of.FILTRE_DEFAUT)
avec = of.eb2pefa(plages["EB"], plages["CM"], *args)
eb_exemple = sans_total(plages["EB"])
outil_exemple = of.eb2pefa(eb_exemple, plages["CM"], *args)
explicite_exemple = pefa_explicite(plage_en_long(eb_exemple), matrice_defaut, classification)
ecarts = comparer(outil_exemple, explicite_exemple)
assert ecarts["ecart"].abs().max() < TOLERANCE_PJ
print(f"Avec la colonne Total : {equilibre(avec)}")
print(f"Sans la colonne Total : {equilibre(outil_exemple)}")
print(f"Couche explicite : {ecarts.height} cellules, écart maximal avec l'outil {ecarts['ecart'].abs().max():.2e} PJ")
```

::: {.callout-note}
## Decision
The tool is used as it is, with no change to its code or to its default matrix. The correction applies to the input data. The `Energy_Balance` range is passed without the « Total » column, for the example as for Tunisia (function `sans_total` above and list `PRODUITS_MODELE` at the top of the page). The folder `outils-fmi/` describes this choice in its `README.md` file. The double count is reported to the author of the tool.
:::

## Accounts for Tunisia

### With the default matrix

For each year, the reference layer receives the balance transferred into the template (page 10) and the default matrix of the tool. The explicit layer receives the same data.

```{python}
#| label: tunisie-defaut
ANNEES = sorted(modele["annee"].unique().to_list())


def bilan_annee(annee: int) -> pl.DataFrame:
    return modele.filter(pl.col("annee") == annee).select(
        pl.col("flux_modele").alias("EB_Flow"), pl.col("produit_modele").alias("EB_Product"), pl.col("tj").alias("Energy")
    )


def plage_annee(annee: int) -> list[list]:
    return of.bilan_vers_plage(modele.filter(pl.col("annee") == annee), FLUX_MODELE, PRODUITS_MODELE)


def matrice_en_plage(matrice: pl.DataFrame) -> list[list]:
    """Matrice polars en plage Excel : en-tête puis lignes, cellules vides à None."""
    colonnes = [str(c) for c in plages["CM"][0]]
    return [colonnes] + [list(r) for r in matrice.select(colonnes).iter_rows()]


def deux_couches(annee: int, matrice: pl.DataFrame) -> tuple[pl.DataFrame, pl.DataFrame]:
    outil = of.eb2pefa(plage_annee(annee), matrice_en_plage(matrice), *args).with_columns(annee=pl.lit(annee, pl.Int16))
    explicite = pefa_explicite(bilan_annee(annee), matrice, classification).with_columns(annee=pl.lit(annee, pl.Int16))
    return outil, explicite


def resume_comparaison(resultats: dict) -> pl.DataFrame:
    lignes = []
    for annee, (outil, explicite) in resultats.items():
        ecarts = comparer(outil.drop("annee"), explicite.drop("annee"))
        lignes.append({
            "annee": annee, "cellules": ecarts.height, "ecart_max_pj": ecarts["ecart"].abs().max(),
            "ressources_pj": equilibre(explicite)["Supply"], "emplois_pj": equilibre(explicite)["Use"],
        })
    return pl.DataFrame(lignes).with_columns(
        ressources_moins_emplois_ktep=((pl.col("ressources_pj") - pl.col("emplois_pj")) * 1000 / 41.868).round(1)
    )


resultats_defaut = {a: deux_couches(a, matrice_defaut) for a in ANNEES}
resume_defaut = resume_comparaison(resultats_defaut)
assert resume_defaut["ecart_max_pj"].max() < TOLERANCE_PJ
resume_defaut
```

### With the Tunisian matrix

The Tunisian matrix (page 12) assigns energy to the 24 SUT industries and to households. The tool accepts these activity codes unchanged, because it treats only the pseudo-activities « RoW », « Acc » and « Env » separately. The two layers are therefore compared at industry level.

```{python}
#| label: tunisie-branches
resultats = {
    a: deux_couches(a, concordance_tunisie.filter(pl.col("annee") == a).drop("annee"))
    for a in ANNEES
}
resume = resume_comparaison(resultats)
assert resume["ecart_max_pj"].max() < TOLERANCE_PJ
resume
```

The statistical difference appears in uses, on its separate row, with the IEA sign. Total supply and total use still differ by a few ktoe, as the last column shows. This difference comes from the rounding of the cells of the published balance, already noted in the identity check of page 10. The balance check by product is done on the next page.

## Saving

The accounts kept are those of the explicit layer with the Tunisian matrix, converted to TJ.
