1 Purpose

This page links the AEA of the previous page to the national inventory, checks their consistency with the PEFA, computes emission intensities by industry and exports everything to an Excel workbook in French, English and Arabic.

from pathlib import Path

import polars as pl
import xlsxwriter

CODES = {"code": pl.String, "activite": pl.String}
PRODUITS = Path("data/produits")
NOM = "comptes_aea"
GAZ = ["CO2", "CH4", "N2O", "F-gases"]

aea = pl.read_parquet("data/intermediaires/aea.parquet")
inventaire = pl.read_parquet("data/intermediaires/inventaire_ges.parquet")
pefa = pl.read_parquet("data/intermediaires/pefa.parquet")
tre = pl.read_parquet("data/intermediaires/tre.parquet")
activites = pl.read_csv("data/nomenclatures/activites.csv", schema_overrides=CODES)
gaz = pl.read_csv("data/nomenclatures/gaz.csv")
passage_lignes = pl.read_csv("data/nomenclatures/aea_passage.csv")
libelles = pl.read_csv("data/nomenclatures/libelles.csv")
ANNEES = sorted(aea["annee"].unique().to_list())
ACTIVITES = [c for c in activites["code"] if c not in ("RDM", "ACC", "ENV", "ECART")]
LIBELLES_FR = dict(activites.select("code", "fr").iter_rows())

2 Bridge table

The AEA follow the residence principle, and the inventory follows the territory principle. The bridge table explains the difference (Eurostat, 2015). Starting from the AEA, it removes the emissions of residents abroad and adds those of non-residents on the territory. It also adds other adjustments, then LULUCF, to arrive at the inventory total.

Maritime transport of residents abroad needs a correction. The tool adds the positive difference between resident vessels and domestic navigation to the activities, without recording it in the bridging item (page 22). The table rebuilds this item from the emissions with source ALL_VESSELS assigned to activities. The code checks that the bridge arrives at the inventory excluding LULUCF of page 20, gas by gas and year by year.

def par_gaz(table: pl.DataFrame, element: str) -> pl.DataFrame:
    return table.group_by("annee", "gaz").agg(kt=pl.col("kt_eq_co2").sum()).with_columns(element=pl.lit(element))


detail = aea.filter(pl.col("gaz") != "GHG")
elements = pl.concat([
    par_gaz(detail.filter(pl.col("activite") == "AEA-TOTAL"), "AEA"),
    *[par_gaz(detail.filter(pl.col("activite") == e), e) for e in ["NRA-AIR", "NRT-AIR", "NRT-WATER", "OTHER", "LULUCF"]],
    # Écart positif des navires ajouté aux activités par l'outil, sans élément de passage
    par_gaz(detail.filter(pl.col("source") == "ALL_VESSELS", pl.col("activite").is_in(ACTIVITES)), "NRA-WATER"),
    par_gaz(inventaire.filter(pl.col("perimetre") == "inventaire"), "INV"),
])
elements = pl.concat([elements, elements.group_by("annee", "element").agg(pl.col("kt").sum()).with_columns(gaz=pl.lit("GHG")).select(elements.columns)])
passage = (
    elements.pivot("element", index=["annee", "gaz"], values="kt")
    .fill_null(0)
    .with_columns(pl.lit(0.0).alias(c) for c in ["NRA-AIR", "NRA-WATER", "NRT-AIR", "NRT-WATER", "OTHER"] if c not in elements["element"])
    .with_columns(calcul=pl.col("AEA") - pl.col("NRA-AIR") - pl.col("NRA-WATER") + pl.col("NRT-AIR") + pl.col("NRT-WATER") + pl.col("OTHER"))
    .with_columns(ecart=pl.col("calcul") - pl.col("INV"), **{"INV-TOTAL": pl.col("INV") + pl.col("LULUCF")})
    .sort("annee", "gaz")
)
assert passage["ecart"].abs().max() < 1e-6, "Le passage des comptes AEA à l'inventaire ne boucle pas"
print(f"Écart maximal entre le passage et l'inventaire : {passage['ecart'].abs().max():.1e} kt")

ORDRE = passage_lignes.sort("ordre")["code"].to_list()
LIBELLES_PASSAGE = dict(passage_lignes.select("code", "fr").iter_rows())
(
    passage.filter(pl.col("gaz") == "GHG")
    .unpivot(index="annee", on=ORDRE, variable_name="code", value_name="kt")
    .with_columns(pl.col("kt").round(1))
    .pivot("annee", index="code", values="kt")
    .with_columns(element=pl.col("code").replace_strict(LIBELLES_PASSAGE))
    .select("element", pl.exclude("code", "element"))
)

The INV-TOTAL total of the tool does not match the inventory. The tool sums the bridging items without regard to their sign. Its activity table does carry the “-” sign for residents abroad, and the code reads it (lines 521 to 524 of I2A.py), but the product is not used in the totals. The tool total therefore exceeds the inventory by twice the air transport of residents abroad, plus the maritime transport that the tool did not record as a bridging item. The following table checks this.

total_outil = aea.filter(pl.col("gaz") == "GHG", pl.col("activite") == "INV-TOTAL").select("annee", outil="kt_eq_co2")
(
    passage.filter(pl.col("gaz") == "GHG")
    .join(total_outil, on="annee")
    .select(
        "annee",
        pl.col("INV-TOTAL").alias("inventaire"),
        "outil",
        (pl.col("outil") - pl.col("INV-TOTAL")).alias("ecart"),
        (2 * pl.col("NRA-AIR") + pl.col("NRA-WATER")).alias("deux_nra_air_plus_nra_water"),
    )
    .with_columns(pl.exclude("annee").round(1))
)
NoteOpen question

Two points should be reported to the author of the tool. The INV-TOTAL total ignores the sign of the bridging items. The positive difference for maritime transport is not recorded in the bridging item NRA-WATER, because the test on line 425 looks at the index of the activity table and not at its codes.

3 Residents abroad and international bunkers

The OECD data give the emissions of resident carriers, wherever they refuel. The international bunkers of the inventory (memo items 1.D) give the emissions of fuel sold in Tunisia to international carriers, resident or not. The two concepts differ, but their orders of magnitude can be compared. For air transport, they are of the same order of magnitude. For maritime transport, resident vessels emit far more than the marine bunkers sold in Tunisia. The OECD maritime data start only in 2019.

soutes = (
    inventaire.filter(pl.col("crt").is_in(["1.D.1.a", "1.D.1.b"]), pl.col("gaz") == "CO2")
    .pivot("crt", index="annee", values="kt", aggregate_function="sum")
    .rename({"1.D.1.a": "soutes_aviation", "1.D.1.b": "soutes_navigation"})
)
(
    passage.filter(pl.col("gaz") == "CO2")
    .select("annee", ocde_aerien_residents="NRA-AIR", ocde_navires_residents="NRA-WATER")
    .join(soutes, on="annee")
    .select("annee", "soutes_aviation", "ocde_aerien_residents", "soutes_navigation", "ocde_navires_residents")
    .with_columns(pl.exclude("annee").round(1))
    .sort("annee")
)
NoteOpen question

The OECD estimate for vessels operated by residents is far higher than the marine bunkers of the inventory. It should be compared with data from INS, ONEM and the Merchant Navy and Ports Office (OMMP) on the Tunisian fleet and its refuelling abroad. The absence of maritime data before 2019 creates a break in series in the accounts of the transport industry.

4 Plausibility against the PEFA

The CO2 emissions from combustion (category 1.A) of an industry come from the fossil fuels it uses. The PEFA give this use in terajoules (page 14). The ratio between the two is an implied emission factor, in tonnes of CO2 per terajoule. It should stay within the range of the implied factors of the inventory itself, computed by fuel type for combustion in category 1.A, with the activity data in TJ of the CRT tables (Intergovernmental Panel on Climate Change, 2006).

crt = pl.read_parquet("data/intermediaires/crt.parquet").filter(pl.col("annee") == 2022, pl.col("crt").str.starts_with("1.A."))
activite_tj = crt.filter(pl.col("parametre") == "activity", pl.col("unite") == "TJ").group_by("combustible").agg(tj=pl.col("valeur").sum())
co2_kt = crt.filter(pl.col("parametre") == "emission", pl.col("gaz") == "CO2").group_by("combustible").agg(co2_kt=pl.col("valeur").sum())
(
    activite_tj.join(co2_kt, on="combustible")
    .filter(pl.col("tj") > 0, ~pl.col("combustible").is_in(["biomass"]))
    .with_columns(t_co2_par_tj=(1000 * pl.col("co2_kt") / pl.col("tj")).round(1), tj=pl.col("tj").round(0))
    .sort("t_co2_par_tj")
)

A gap signals a different allocation in the two accounts. Non-energy use of petroleum products, counted in the PEFA without combustion emissions, lowers the ratio. The residence adjustments for air and maritime transport, absent from the PEFA, raise it for the transport industry.

COMBUSTIBLES_FOSSILES = ["Coal", "Peat and peat products", "Oil shale / oil sands", "Natural gas", "Oil"]
energie = (
    pefa.filter(
        pl.col("quadrant") == "Use",
        pl.col("niveau2") == "End-use of energy products by SIEC class:",
        pl.col("produit").is_in(COMBUSTIBLES_FOSSILES),
        pl.col("activite").is_in(ACTIVITES),
    )
    .group_by("annee", "activite")
    .agg(energie_tj=pl.col("tj").sum())
)
co2_combustion = (
    aea.filter(pl.col("gaz") == "CO2", pl.col("source").str.starts_with("1.A."), pl.col("activite").is_in(ACTIVITES))
    .group_by("annee", "activite")
    .agg(co2_kt=pl.col("kt_eq_co2").sum())
)
facteurs = (
    co2_combustion.join(energie, on=["annee", "activite"], how="full", coalesce=True)
    .with_columns(pl.col("co2_kt", "energie_tj").fill_null(0))
    .with_columns(t_co2_par_tj=pl.when(pl.col("energie_tj") > 0).then(1000 * pl.col("co2_kt") / pl.col("energie_tj")))
    .rename({"energie_tj": "combustibles_fossiles_tj"})
)
(
    facteurs.filter(pl.col("annee") == 2022)
    .with_columns(libelle=pl.col("activite").replace_strict(LIBELLES_FR, default=None))
    .select("activite", "libelle", pl.col("co2_kt").round(1), pl.col("combustibles_fossiles_tj").round(0), pl.col("t_co2_par_tj").round(1))
    .sort("activite")
)
NoteOpen question

Both accounts allocate road transport and services with the same keys. The remaining gaps come mainly from different classifications between the balance and the inventory, for example for the consumption of the energy industry and electricity autoproduction. They are to be examined with ONEM and ANME during the mission.

5 Emission intensities

The emission intensity of an industry relates its greenhouse gas emissions to its output or its value added, in tonnes of CO2 equivalent per million current dinars. For households, the denominator is final consumption expenditure, as the tool manual suggests (International Monetary Fund, 2026). These indicators follow the SUT at current prices, so their changes mix volumes and prices.

comptes_production = (
    tre.filter(pl.col("bloc") == "valeur_ajoutee", pl.col("ligne").is_in(["P1", "B1G"]))
    .pivot("ligne", index=["annee", "colonne"], values="valeur")
    .rename({"colonne": "activite", "P1": "production_mdt", "B1G": "valeur_ajoutee_mdt"})
)
depense_menages = (
    tre.filter(pl.col("bloc") == "emplois", pl.col("colonne") == "P3_MEN", ~pl.col("agregat"))
    .group_by("annee")
    .agg(depense_men_mdt=pl.col("valeur").sum())
    .with_columns(activite=pl.lit("MEN"))
)
ges = (
    aea.filter(pl.col("gaz") == "GHG", pl.col("activite").is_in(ACTIVITES))
    .group_by("annee", "activite")
    .agg(emissions_ges_kt=pl.col("kt_eq_co2").sum())
)
indicateurs = (
    ges.join(comptes_production, on=["annee", "activite"], how="left")
    .join(depense_menages, on=["annee", "activite"], how="left")
    .with_columns(
        intensite_ges_production=1000 * pl.col("emissions_ges_kt") / pl.col("production_mdt"),
        intensite_ges_va=1000 * pl.col("emissions_ges_kt") / pl.col("valeur_ajoutee_mdt"),
        intensite_ges_men=1000 * pl.col("emissions_ges_kt") / pl.col("depense_men_mdt"),
    )
    .sort("annee", "activite")
)
(
    indicateurs.filter(pl.col("annee") == 2022)
    .with_columns(libelle=pl.col("activite").replace_strict(LIBELLES_FR))
    .select("activite", "libelle", pl.col("emissions_ges_kt").round(1), pl.col("intensite_ges_va", "intensite_ges_men").round(1))
    .sort("intensite_ges_va", descending=True, nulls_last=True)
)

6 Export

The workbook contains a notes sheet, the long table of all years with the original CRT category, the bridge table, one sheet per year with activities in rows and gases in columns, and the indicators. Activity labels come from data/nomenclatures/activites.csv, gas labels from data/nomenclatures/gaz.csv, bridge labels from data/nomenclatures/aea_passage.csv, and headers from data/nomenclatures/libelles.csv. The Arabic sheets run from right to left.

def traduire(langue: str) -> tuple[dict, dict, dict, dict]:
    t = dict(zip(libelles["cle"], libelles[langue]))
    a = dict(zip(activites["code"], activites[langue]))
    g = dict(zip(gaz["code"], gaz[langue]))
    p = dict(zip(passage_lignes["code"], passage_lignes[langue]))
    return t, a, g, p


def tableau_annee(annee: int, langue: str) -> pl.DataFrame:
    """Émissions d'une année : activités en lignes, gaz en colonnes, avec le total."""
    t, a, g, _ = traduire(langue)
    donnees = aea.filter(pl.col("annee") == annee, pl.col("activite").is_in(ACTIVITES))
    large = (
        donnees.group_by("activite", "gaz").agg(pl.col("kt_eq_co2").sum())
        .pivot("gaz", index="activite", values="kt_eq_co2")
        .with_columns(ordre=pl.col("activite").replace_strict({c: i for i, c in enumerate(ACTIVITES)}, return_dtype=pl.Int16))
        .sort("ordre")
    )
    colonnes = [c for c in GAZ + ["GHG"] if c in large.columns]
    large = large.with_columns(pl.col(colonnes).fill_null(0))
    total = large.select(pl.col(colonnes).sum()).with_columns(activite=pl.lit(None, dtype=pl.String), ordre=pl.lit(999, dtype=pl.Int16))
    large = pl.concat([large, total.select(large.columns)])
    return large.select(
        pl.col("activite").alias(t["code_activite"]),
        pl.col("activite").replace_strict(a, default=t["total"]).alias(t["activite"]),
        *[pl.col(c).alias(g[c]) for c in colonnes],
    )


def passage_traduit(langue: str) -> pl.DataFrame:
    t, _, _, p = traduire(langue)
    return (
        passage.filter(pl.col("gaz") == "GHG")
        .unpivot(index="annee", on=ORDRE, variable_name="code", value_name="kt")
        .pivot("annee", index="code", values="kt")
        .select(pl.col("code").replace_strict(p).alias(t["element_passage"]), pl.exclude("code"))
    )


def donnees_longues(langue: str) -> pl.DataFrame:
    t, a, g, _ = traduire(langue)
    return aea.filter(pl.col("activite").is_in(ACTIVITES)).select(
        pl.col("annee").alias(t["annee"]),
        pl.col("gaz").replace_strict(g).alias(t["gaz"]),
        pl.col("source").alias(t["categorie_crt"]),
        pl.col("activite").alias(t["code_activite"]),
        pl.col("activite").replace_strict(a).alias(t["activite"]),
        pl.col("kt_eq_co2").alias(t["kt_eq_co2"]),
    )


def indicateurs_traduits(langue: str) -> pl.DataFrame:
    t, a, _, _ = traduire(langue)
    colonnes = ["emissions_ges_kt", "production_mdt", "valeur_ajoutee_mdt", "depense_men_mdt",
                "intensite_ges_production", "intensite_ges_va", "intensite_ges_men"]
    return indicateurs.select(
        pl.col("annee").alias(t["annee"]),
        pl.col("activite").alias(t["code_activite"]),
        pl.col("activite").replace_strict(a).alias(t["activite"]),
        *[pl.col(c).alias(t[c]) for c in colonnes],
    )


def exporter(langue: str) -> Path:
    t, _, _, _ = traduire(langue)
    dossier = PRODUITS / langue
    dossier.mkdir(parents=True, exist_ok=True)
    chemin = dossier / f"{NOM}.xlsx"
    with xlsxwriter.Workbook(chemin) as classeur:
        notes = classeur.add_worksheet(t["feuille_notes"])
        for i, cle in enumerate(["titre_aea", "unite_kt_eq", "note_source_aea", "note_methode_aea", "note_provisoire", "note_site"]):
            notes.write(i, 0, t[cle])
        feuilles = [(t["feuille_donnees"], donnees_longues(langue), 3), (t["feuille_passage"], passage_traduit(langue), 1)]
        feuilles += [(f"{t['feuille_aea']} {annee}", tableau_annee(annee, langue), 1) for annee in ANNEES]
        feuilles.append((t["feuille_indicateurs"], indicateurs_traduits(langue), 1))
        for nom, tableau, decimales in feuilles:
            tableau.write_excel(workbook=classeur, worksheet=nom, autofit=True, float_precision=decimales)
        if langue == "ar":
            for feuille in classeur.worksheets():
                feuille.right_to_left()
    return chemin


for langue in ["fr", "en", "ar"]:
    print(exporter(langue))

```{python}
    .select("element", pl.exclude("code", "element"))
)
```

The `INV-TOTAL` total of the tool does not match the inventory. The tool sums the bridging items without regard to their sign. Its activity table does carry the "-" sign for residents abroad, and the code reads it (lines 521 to 524 of `I2A.py`), but the product is not used in the totals. The tool total therefore exceeds the inventory by twice the air transport of residents abroad, plus the maritime transport that the tool did not record as a bridging item. The following table checks this.

```{python}
#| label: total-outil
total_outil = aea.filter(pl.col("gaz") == "GHG", pl.col("activite") == "INV-TOTAL").select("annee", outil="kt_eq_co2")
(
    passage.filter(pl.col("gaz") == "GHG")
    .join(total_outil, on="annee")
    .select(
        "annee",
        pl.col("INV-TOTAL").alias("inventaire"),
        "outil",
        (pl.col("outil") - pl.col("INV-TOTAL")).alias("ecart"),
        (2 * pl.col("NRA-AIR") + pl.col("NRA-WATER")).alias("deux_nra_air_plus_nra_water"),
    )
    .with_columns(pl.exclude("annee").round(1))
)
```

::: {.callout-note}
## Open question
Two points should be reported to the author of the tool. The `INV-TOTAL` total ignores the sign of the bridging items. The positive difference for maritime transport is not recorded in the bridging item `NRA-WATER`, because the test on line 425 looks at the index of the activity table and not at its codes.
:::

## Residents abroad and international bunkers

The OECD data give the emissions of resident carriers, wherever they refuel. The international bunkers of the inventory (memo items 1.D) give the emissions of fuel sold in Tunisia to international carriers, resident or not. The two concepts differ, but their orders of magnitude can be compared. For air transport, they are of the same order of magnitude. For maritime transport, resident vessels emit far more than the marine bunkers sold in Tunisia. The OECD maritime data start only in 2019.

```{python}
#| label: soutes
soutes = (
    inventaire.filter(pl.col("crt").is_in(["1.D.1.a", "1.D.1.b"]), pl.col("gaz") == "CO2")
    .pivot("crt", index="annee", values="kt", aggregate_function="sum")
    .rename({"1.D.1.a": "soutes_aviation", "1.D.1.b": "soutes_navigation"})
)
(
    passage.filter(pl.col("gaz") == "CO2")
    .select("annee", ocde_aerien_residents="NRA-AIR", ocde_navires_residents="NRA-WATER")
    .join(soutes, on="annee")
    .select("annee", "soutes_aviation", "ocde_aerien_residents", "soutes_navigation", "ocde_navires_residents")
    .with_columns(pl.exclude("annee").round(1))
    .sort("annee")
)
```

::: {.callout-note}
## Open question
The OECD estimate for vessels operated by residents is far higher than the marine bunkers of the inventory. It should be compared with data from INS, ONEM and the Merchant Navy and Ports Office (OMMP) on the Tunisian fleet and its refuelling abroad. The absence of maritime data before 2019 creates a break in series in the accounts of the transport industry.
:::

## Plausibility against the PEFA

The CO2 emissions from combustion (category 1.A) of an industry come from the fossil fuels it uses. The PEFA give this use in terajoules (page 14). The ratio between the two is an implied emission factor, in tonnes of CO2 per terajoule. It should stay within the range of the implied factors of the inventory itself, computed by fuel type for combustion in category 1.A, with the activity data in TJ of the CRT tables [@ipcc2006].

```{python}
#| label: facteurs-crt
crt = pl.read_parquet("data/intermediaires/crt.parquet").filter(pl.col("annee") == 2022, pl.col("crt").str.starts_with("1.A."))
activite_tj = crt.filter(pl.col("parametre") == "activity", pl.col("unite") == "TJ").group_by("combustible").agg(tj=pl.col("valeur").sum())
co2_kt = crt.filter(pl.col("parametre") == "emission", pl.col("gaz") == "CO2").group_by("combustible").agg(co2_kt=pl.col("valeur").sum())
(
    activite_tj.join(co2_kt, on="combustible")
    .filter(pl.col("tj") > 0, ~pl.col("combustible").is_in(["biomass"]))
    .with_columns(t_co2_par_tj=(1000 * pl.col("co2_kt") / pl.col("tj")).round(1), tj=pl.col("tj").round(0))
    .sort("t_co2_par_tj")
)
```

A gap signals a different allocation in the two accounts. Non-energy use of petroleum products, counted in the PEFA without combustion emissions, lowers the ratio. The residence adjustments for air and maritime transport, absent from the PEFA, raise it for the transport industry.

```{python}
#| label: vraisemblance-pefa
COMBUSTIBLES_FOSSILES = ["Coal", "Peat and peat products", "Oil shale / oil sands", "Natural gas", "Oil"]
energie = (
    pefa.filter(
        pl.col("quadrant") == "Use",
        pl.col("niveau2") == "End-use of energy products by SIEC class:",
        pl.col("produit").is_in(COMBUSTIBLES_FOSSILES),
        pl.col("activite").is_in(ACTIVITES),
    )
    .group_by("annee", "activite")
    .agg(energie_tj=pl.col("tj").sum())
)
co2_combustion = (
    aea.filter(pl.col("gaz") == "CO2", pl.col("source").str.starts_with("1.A."), pl.col("activite").is_in(ACTIVITES))
    .group_by("annee", "activite")
    .agg(co2_kt=pl.col("kt_eq_co2").sum())
)
facteurs = (
    co2_combustion.join(energie, on=["annee", "activite"], how="full", coalesce=True)
    .with_columns(pl.col("co2_kt", "energie_tj").fill_null(0))
    .with_columns(t_co2_par_tj=pl.when(pl.col("energie_tj") > 0).then(1000 * pl.col("co2_kt") / pl.col("energie_tj")))
    .rename({"energie_tj": "combustibles_fossiles_tj"})
)
(
    facteurs.filter(pl.col("annee") == 2022)
    .with_columns(libelle=pl.col("activite").replace_strict(LIBELLES_FR, default=None))
    .select("activite", "libelle", pl.col("co2_kt").round(1), pl.col("combustibles_fossiles_tj").round(0), pl.col("t_co2_par_tj").round(1))
    .sort("activite")
)
```

::: {.callout-note}
## Open question
Both accounts allocate road transport and services with the same keys. The remaining gaps come mainly from different classifications between the balance and the inventory, for example for the consumption of the energy industry and electricity autoproduction. They are to be examined with ONEM and ANME during the mission.
:::

## Emission intensities

The emission intensity of an industry relates its greenhouse gas emissions to its output or its value added, in tonnes of CO2 equivalent per million current dinars. For households, the denominator is final consumption expenditure, as the tool manual suggests [@imf2026i2a]. These indicators follow the SUT at current prices, so their changes mix volumes and prices.

```{python}
#| label: intensites
comptes_production = (
    tre.filter(pl.col("bloc") == "valeur_ajoutee", pl.col("ligne").is_in(["P1", "B1G"]))
    .pivot("ligne", index=["annee", "colonne"], values="valeur")
    .rename({"colonne": "activite", "P1": "production_mdt", "B1G": "valeur_ajoutee_mdt"})
)
depense_menages = (
    tre.filter(pl.col("bloc") == "emplois", pl.col("colonne") == "P3_MEN", ~pl.col("agregat"))
    .group_by("annee")
    .agg(depense_men_mdt=pl.col("valeur").sum())
    .with_columns(activite=pl.lit("MEN"))
)
ges = (
    aea.filter(pl.col("gaz") == "GHG", pl.col("activite").is_in(ACTIVITES))
    .group_by("annee", "activite")
    .agg(emissions_ges_kt=pl.col("kt_eq_co2").sum())
)
indicateurs = (
    ges.join(comptes_production, on=["annee", "activite"], how="left")
    .join(depense_menages, on=["annee", "activite"], how="left")
    .with_columns(
        intensite_ges_production=1000 * pl.col("emissions_ges_kt") / pl.col("production_mdt"),
        intensite_ges_va=1000 * pl.col("emissions_ges_kt") / pl.col("valeur_ajoutee_mdt"),
        intensite_ges_men=1000 * pl.col("emissions_ges_kt") / pl.col("depense_men_mdt"),
    )
    .sort("annee", "activite")
)
(
    indicateurs.filter(pl.col("annee") == 2022)
    .with_columns(libelle=pl.col("activite").replace_strict(LIBELLES_FR))
    .select("activite", "libelle", pl.col("emissions_ges_kt").round(1), pl.col("intensite_ges_va", "intensite_ges_men").round(1))
    .sort("intensite_ges_va", descending=True, nulls_last=True)
)
```

## Export

The workbook contains a notes sheet, the long table of all years with the original CRT category, the bridge table, one sheet per year with activities in rows and gases in columns, and the indicators. Activity labels come from `data/nomenclatures/activites.csv`, gas labels from `data/nomenclatures/gaz.csv`, bridge labels from `data/nomenclatures/aea_passage.csv`, and headers from `data/nomenclatures/libelles.csv`. The Arabic sheets run from right to left.

```{python}
#| label: export
def traduire(langue: str) -> tuple[dict, dict, dict, dict]:
    t = dict(zip(libelles["cle"], libelles[langue]))
    a = dict(zip(activites["code"], activites[langue]))
    g = dict(zip(gaz["code"], gaz[langue]))
    p = dict(zip(passage_lignes["code"], passage_lignes[langue]))
    return t, a, g, p


def tableau_annee(annee: int, langue: str) -> pl.DataFrame:
    """Émissions d'une année : activités en lignes, gaz en colonnes, avec le total."""
    t, a, g, _ = traduire(langue)
    donnees = aea.filter(pl.col("annee") == annee, pl.col("activite").is_in(ACTIVITES))
    large = (
        donnees.group_by("activite", "gaz").agg(pl.col("kt_eq_co2").sum())
        .pivot("gaz", index="activite", values="kt_eq_co2")
        .with_columns(ordre=pl.col("activite").replace_strict({c: i for i, c in enumerate(ACTIVITES)}, return_dtype=pl.Int16))
        .sort("ordre")
    )
    colonnes = [c for c in GAZ + ["GHG"] if c in large.columns]
    large = large.with_columns(pl.col(colonnes).fill_null(0))
    total = large.select(pl.col(colonnes).sum()).with_columns(activite=pl.lit(None, dtype=pl.String), ordre=pl.lit(999, dtype=pl.Int16))
    large = pl.concat([large, total.select(large.columns)])
    return large.select(
        pl.col("activite").alias(t["code_activite"]),
        pl.col("activite").replace_strict(a, default=t["total"]).alias(t["activite"]),
        *[pl.col(c).alias(g[c]) for c in colonnes],
    )


def passage_traduit(langue: str) -> pl.DataFrame:
    t, _, _, p = traduire(langue)
    return (
        passage.filter(pl.col("gaz") == "GHG")
        .unpivot(index="annee", on=ORDRE, variable_name="code", value_name="kt")
        .pivot("annee", index="code", values="kt")
        .select(pl.col("code").replace_strict(p).alias(t["element_passage"]), pl.exclude("code"))
    )


def donnees_longues(langue: str) -> pl.DataFrame:
    t, a, g, _ = traduire(langue)
    return aea.filter(pl.col("activite").is_in(ACTIVITES)).select(
        pl.col("annee").alias(t["annee"]),
        pl.col("gaz").replace_strict(g).alias(t["gaz"]),
        pl.col("source").alias(t["categorie_crt"]),
        pl.col("activite").alias(t["code_activite"]),
        pl.col("activite").replace_strict(a).alias(t["activite"]),
        pl.col("kt_eq_co2").alias(t["kt_eq_co2"]),
    )


def indicateurs_traduits(langue: str) -> pl.DataFrame:
    t, a, _, _ = traduire(langue)
    colonnes = ["emissions_ges_kt", "production_mdt", "valeur_ajoutee_mdt", "depense_men_mdt",
                "intensite_ges_production", "intensite_ges_va", "intensite_ges_men"]
    return indicateurs.select(
        pl.col("annee").alias(t["annee"]),
        pl.col("activite").alias(t["code_activite"]),
        pl.col("activite").replace_strict(a).alias(t["activite"]),
        *[pl.col(c).alias(t[c]) for c in colonnes],
    )


def exporter(langue: str) -> Path:
    t, _, _, _ = traduire(langue)
    dossier = PRODUITS / langue
    dossier.mkdir(parents=True, exist_ok=True)
    chemin = dossier / f"{NOM}.xlsx"
    with xlsxwriter.Workbook(chemin) as classeur:
        notes = classeur.add_worksheet(t["feuille_notes"])
        for i, cle in enumerate(["titre_aea", "unite_kt_eq", "note_source_aea", "note_methode_aea", "note_provisoire", "note_site"]):
            notes.write(i, 0, t[cle])
        feuilles = [(t["feuille_donnees"], donnees_longues(langue), 3), (t["feuille_passage"], passage_traduit(langue), 1)]
        feuilles += [(f"{t['feuille_aea']} {annee}", tableau_annee(annee, langue), 1) for annee in ANNEES]
        feuilles.append((t["feuille_indicateurs"], indicateurs_traduits(langue), 1))
        for nom, tableau, decimales in feuilles:
            tableau.write_excel(workbook=classeur, worksheet=nom, autofit=True, float_precision=decimales)
        if langue == "ar":
            for feuille in classeur.worksheets():
                feuille.right_to_left()
    return chemin


for langue in ["fr", "en", "ar"]:
    print(exporter(langue))
```
