Data processing

From source data to energy and air emissions accounts

The pages in this section describe step by step how the data provided by the authorities become accounts. Each page combines explanations with the Python code that carries them out. The pages are read in the order of their number, because each one uses tables produced by the previous ones.

The French pages run the code. This English version shows the same code without running it; results and tables are in the French pages and on the downloads page. Code comments stay in French, as in the reference version.

11. From balance sectors to industries Correspondence of balance flows with the 24 SUT industries and households, allocation keys for road transport and services

14. Checks, indicators and export of the PEFA Balance of the tables, plausibility against the SUT, energy intensities, workbooks in three languages
